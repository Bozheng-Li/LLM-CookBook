## 一、v2 战役目标

第一轮把页面从「概览式」补到了「书级细粒度」（5000+ 字/页）。v2 要做三件事：

1. **新手教程级**：把每一个概念讲得像给完全没基础的人上课——先类比、再拆解、后公式，每个术语首次出现都给解释，每个结论都给"为什么"。
2. **论文/权威原图**：每页至少嵌入 1 张来自论文或权威来源的原图（替代/补充纯自制 Mermaid），让读者看到"第一手证据"。
3. **内容再丰富**：在已达标基础上继续加深——更多手算例子、更多失败模式、更多逐步推导。

**不是**推倒重写，而是在保留原有准确内容的基础上**深化与换图**。

## 三、论文/权威原图规范（本轮核心）

### 3.1 图片来源（按优先级）

1. **arXiv 论文原图**（首选）：已通过 `tools/fetch_paper_figs.py` / `tools/fetch_figs_all.py` 下载到
   `assets/figures/<part>/<topic>/figN.png`。**优先使用已下载的图**，不要重新外链。
2. 论文/权威来源的**外链图**（arXiv HTML 版、PapersWithCode、官方博客），仅当本地无图且确实必要时。
3. 自制 Mermaid / Chart.js（保留原有，用于补充说明，不替代论文图）。

### 3.2 页面嵌入格式（固定模板）

```html
<figure class="paper-figure">
  <img src="../../assets/figures/<part>/<topic>/fig1.png" alt="论文原图：一句话说明" loading="lazy" style="max-width:520px">
  <figcaption>
    <span class="pf-title">图：图的含义标题</span>
    <span class="pf-src">论文原图 · 作者, <em>论文标题</em>, 年份, Figure N · <a href="https://arxiv.org/abs/<id>" target="_blank" rel="noopener">arXiv:&lt;id&gt;</a></span>
  </figcaption>
</figure>
```

要点：
- `src` 用**相对路径**（页面在 `pages/<part>/` 下，图片在 `assets/figures/` 下，故前缀 `../../assets/figures/`）。
- `alt` 必须写清楚图在讲什么（可访问性）。
- 作者/标题/年份/Figure 编号/arXiv id 必须与图真实对应，**禁止编造**。
- 论文图通常为英文原图，**图下必须补 1-2 段中文解读**，逐块讲解图上元素（手把手读图），新手才看得懂。
- 图注 `pf-src` 里对英文标题用 `<em>` 包裹。

### 3.3 每页图布局建议

- 「一图看懂」保留 Mermaid 概览图（画得好的自制图不必删除）。
- 正文中再嵌 1-2 张论文原图，放在最对应的章节，并围绕它讲。
- 已有论文图的页面（见 `tools/fig-map.json` 中 `status: done`）直接复用本地图。

### 3.4 常见错误

- ❌ 从网上随便找图但来源不明/无法核实 → 违规范
- ❌ 图与文字描述不一致（图讲的是训练曲线却当架构图用）→ 违规范
- ❌ 下载后路径写错（少一个 `../`）→ 死图
- ❌ 论文作者/年份写错 → 违规范
- ✅ 拿不准的细节写「以官方文档为准」，不编造

## 四、新手教程级写法（v2 写作内核）

每个 `<h2>` 小节按「上课」节奏写，四步曲：

1. **生活化类比引入（30-80 字）**：先把概念翻译成日常经验。例：讲 KV Cache 前先说「做数学题时草稿纸上的中间步骤，答案接近了但草稿还在占地方」。
2. **机制拆解**：把机制切成 2-4 个可独立理解的小块，每块单独一段，先定性后定量。
3. **具体例子 + 手算**：带读者算一遍。例：7B 模型 FP16 显存 = 7×10⁹×2 ≈ 14GB；注意力分数 3 个 token 的 softmax 手算。
4. **失败模式与坑**：什么情况下会出错、实际工程怎么权衡。

**术语纪律（新手友好核心）：**
- 每个英文术语首次出现时给中文译名 + 一句话直觉，例：「KV Cache（键值缓存）——把算过的注意力键值存下来，避免重复计算」。
- 避免连续堆名词；一段话只推进一个知识点。
- 公式旁边必须有中文解释「这个式子在算哪一步、每项代表什么」。
- 数字具体化；不确定的写「以官方文档为准」。

**每页必备的教程元素（在 v1 基础上）：**
- 「一图看懂」：保留并改写得更好懂。
- ≥2 个 `details.deep`：一个放「手算/推导」，一个放「踩坑实录/调参记录」。
- 至少 1 个「动手试」：给一段能跑的代码或一个 1 分钟可做的实验（代码不计字数，解读计入）。
- 一个「新手最容易搞错」callout（`callout warn`）：把该主题最常见的误解单独拎出来讲。
