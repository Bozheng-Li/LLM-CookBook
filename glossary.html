分层术语表

术语按知识依赖分层。每一项先给出一句可操作的定义，再链接到本书中的完整推导；不认识时从上往下读，不必一次加载整张长名单。

阅读顺序：基础对象 → 表示与架构 → 训练与推理 → 应用与系统 → 评测与治理。术语的定义优先于缩写，章节链接用于继续深入。

第一层：基础对象

Token（词元）

模型处理的最小离散符号，可能是字符、子词或字节；上下文长度和成本都按 token 计。

词元化

Embedding（嵌入）

把离散 token id 映射到连续向量空间的可学习表，向量距离可表达部分语义关系。

词嵌入与向量空间

Logit

Softmax 前对词表候选的未归一化分数；温度、重复惩罚和约束解码都作用在它附近。

解码策略

Cross-Entropy（交叉熵）

真实分布对模型预测分布的平均编码代价，是语言模型 next-token 训练的常用损失。

概率与信息论

Gradient（梯度）

损失对参数的偏导数组成的方向，优化器据此决定参数更新。

微积分与反向传播

Attention（注意力）

用 Query 与 Key 的匹配分数对 Value 加权读取，使每个位置动态选择上下文信息。

注意力机制

第二层：表示与架构

Transformer

以自注意力和前馈网络为核心、可并行处理序列的网络架构，decoder-only LLM 多由其堆叠而成。

完整架构

RoPE

将位置信息编码为 Query/Key 的旋转，使内积自然携带相对位置关系。

位置编码

KV Cache

缓存已处理 token 的 Key/Value，避免 decode 时重复计算；代价是随序列和并发增长的显存。

KV Cache

GQA

多个 Query 头共享较少的 Key/Value 头，在保留多 Query 表达能力的同时降低缓存带宽。

注意力变体

MoE

每个 token 只激活少数专家网络，将总参数容量与单 token 计算量分离。

混合专家

RMSNorm

只按均方根缩放隐藏状态、不计算均值的归一化方法，常用于现代 Transformer 的 Pre-Norm 结构。

归一化技术

第三层：训练与推理

Scaling Law

描述损失随模型、数据和计算预算变化的经验幂律，用于训练预算外推而非保证能力涌现。

Scaling Laws

SFT

用示范输入-输出对监督微调，通常只对 assistant 回复 token 计算损失。

监督微调

DPO

直接利用 chosen/rejected 偏好对优化策略相对参考模型的 log-prob 差异，无需单独训练奖励模型。

DPO

RLVR

用可执行验证器产生奖励的强化学习，例如单元测试、数学答案检查或格式校验。

GRPO / RLVR

Speculative Decoding

草稿模型先生成候选，主模型并行验证并接受前缀，以较低成本减少串行解码。

投机解码

Quantization（量化）

用更低位宽表示权重或激活，减少显存和带宽，但会引入可测的近似误差。

量化

第四层：应用与 Agent 系统

RAG

先从外部知识库检索证据，再把片段交给生成模型回答，降低知识陈旧和不可引用问题。

RAG

Reranker（重排器）

对初召回候选做更精确的 query-document 相关性打分，通常牺牲延迟换取排序质量。

Advanced RAG

Agent

在目标、状态、工具和环境反馈组成的循环中自主选择动作，并接受预算与终止条件约束。

Agent 基础

Tool Calling

模型输出符合 schema 的函数名和参数，由宿主执行并把结果作为下一轮 observation。

工具调用与 MCP

MCP

规定客户端与服务端如何发现工具、资源和提示的开放协议，不等于权限或安全策略。

MCP 深度解析

Context Engineering

对上下文预算、排序、压缩、工具描述和记忆进行系统设计，而不只修改 prompt 文案。

上下文工程

第五层：评测与治理

Faithfulness（忠实性）

回答中的陈述是否能被提供的证据支持，常用于 RAG 评测，和“事实是否真实”不是同一概念。

幻觉与事实性

Pass@k

从 k 个候选中至少有一个通过测试的概率估计，适合代码和可验证推理任务。

评估基准

Contamination（数据污染）

评测题或近似文本出现在训练数据中，使分数混入记忆而非泛化能力。

数据污染

LLM-as-Judge

使用另一个语言模型按 rubric 评判输出，成本低但需校准位置偏差、长度偏差和与人工的一致性。

评估方法论

Guardrail（护栏）

在输入、工具调用或输出处执行的规则、分类器和验证器，用于阻断高风险行为。

护栏与输出校验

Model Card

记录模型用途、限制、评测数据和已知风险的发布文档，帮助使用者判断适用边界。

治理框架
