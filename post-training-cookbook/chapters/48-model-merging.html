第 9 部分 · 前沿专题

第 48 章 · 模型融合（Model Merging）

如果我们可以像算术运算一样相加、相减甚至插值多个大语言模型的参数，会发生什么？模型融合（Model Merging）打破了“必须耗费昂贵算力重新训练才能融合能力”的传统范式，利用权重空间的几何特性与线性模式连接，在零额外训练数据与零推理延迟的前提下，将多个独立微调的领域模型无缝拼接为复合多能模型。本章系统解构模型融合的损失景观理论、主流融合算子（Task Arithmetic、SLERP、Fisher 加权、TIES-Merging 与 DARE）、后训练能力组合方案，并结合 MergeKit 与 PyTorch 提供工业级融合落地实战。

1. 权重空间的炼金术：为什么模型可以被合并？

在大模型后训练领域，一个长期存在的工程困境是：“多任务全量微调”的计算开销与数据冲突。当我们希望一个基座大模型既精通 Python 编程、又具备出色的中文文案写作能力、同时还保持顶级的数学推导水平与严格的安全对齐防线时，最直觉的做法是将所有领域的数据汇集在一起进行多任务联合微调（Multi-Task SFT）或连续强化学习。然而，联合训练不仅面临跨领域梯度互冲（Negative Transfer / Gradient Conflict）与灾难性遗忘，还需要调动数百乃至上千张 GPU 重新训练数天甚至数周。

能否跳过昂贵的反向传播，直接对多个在不同任务上分别微调好的模型权重执行“参数合并”？这种看似违背深度学习非线性黑盒直觉的技术，被称为 模型融合（Model Merging）。令人惊叹的是，在当今千亿级参数的大模型生态中，多个微调模型的直接权重相加或加权平均，常常不仅没有使模型瘫痪崩溃，反而能在各个任务上展现出媲美甚至超越独立微调专家的综合表现。

📘 核心直觉：权重空间为什么具有线性可组合性？

深度神经网络的损失曲面（Loss Landscape）是高度非凸、崎岖不平且充斥着局部极小值的。如果随意将两个从随机高斯分布分别初始化训练出的神经网络权重取算术平均，所得模型在几乎所有任务上的损失都会剧烈飙升至天文数字。模型融合能够生效的唯一决定性前提在于：所有参与融合的模型都必须源自同一个预训练基座（Shared Pretrained Initialization）。

1.1 线性模式连接（Linear Mode Connectivity, LMC）

深度学习理论中的 线性模式连接（Linear Mode Connectivity, LMC） 假说指出：在满足特定初始化条件时，神经网络在参数空间中收敛到的两个不同极小值点 \(\theta_A\) 与 \(\theta_B\) 之间，存在一条低损失的连通路径。更严格地，当这条路径是一条连接两点的欧几里得直线段时，我们称其满足严格的线性模式连接：

\[ \forall \alpha \in [0, 1], \quad \mathcal{L}((1 - \alpha)\theta_A + \alpha \theta_B) \le (1 - \alpha)\mathcal{L}(\theta_A) + \alpha \mathcal{L}(\theta_B) + \epsilon \]

式中 \(\epsilon\) 表示路径上的损失障碍（Loss Barrier）。如果 \(\epsilon \approx 0\)，说明从模型 A 到模型 B 的直线插值过程中完全没有越过高耸的损失山峰，二者处于同一平缓的凸状低损失盆地（Flat Convex Basin）内。

Nagarajan 等人与 Frankle 等人的实证研究表明：从完全不同的随机初始化点出发训练得到的两个模型，由于置换对称性（Permutation Symmetry）的存在，中间隔着极高的能量壁垒（\(\epsilon \gg 0\)）；然而，只要两个模型微调前使用的是同一个预训练检查点 \(\theta_0\)，后训练的微调过程本质上只是在该预训练吸引子（Attractor Basin）附近进行微小的局部切空间漂移。由于微调移动的距离相较于整个高维权重空间的半径极其微小，不同微调模型几乎始终停留在此单峰盆地内部，这构成了模型融合最坚实的几何与优化理论地基。

本节小结：预训练阶段赋予了模型一个通用的底层语义坐标系；随后的 SFT 或偏好微调只是在局部切平面上施加位移向量。只要微调没有破坏基础表征流形，这些切向量在很大程度上是相互兼容的。

2. 任务向量与几何插值：从线性平均到 Task Arithmetic

理解了线性模式连接后，我们将问题形式化为数学操作。本节探讨基础融合算法：朴素加权平均、球面线性插值（SLERP）以及革命性的任务算术（Task Arithmetic）。

2.1 任务向量（Task Vector）数学定义

设 \(\theta_0 \in \mathbb{R}^d\) 为共享的预训练基座模型参数（参数维度 \(d\) 通常为数十亿至数千亿）。在特定任务 \(t\)（例如代码指令、安全对齐、法律问答）上微调后得到模型参数 \(\theta_t\)。Ilharco 等人（2022）提出了著名的 任务向量（Task Vector） 概念：

\[ \tau_t = \theta_t - \theta_0 \]

任务向量 \(\tau_t\) 刻画了为了适应该任务，模型参数需要发生改变的高维位移方向与步长。直观而言，\(\tau_t\) 提炼了模型在后训练中获取的新知识增量，剔除了底座原有的共性表征。

2.2 任务算术（Task Arithmetic）的代数运算

既然 \(\tau_t\) 是参数空间中的向量，那么向量空间的标准代数运算（加法、数乘、减法）就具备了清晰的语义解释：

  • 多任务技能叠加（Addition / Multi-Task Merging）：将针对不同任务独立训练的多个任务向量加权相加，与基座模型复合： \[ \theta_{\mathrm{merge}} = \theta_0 + \lambda \sum_{i=1}^M \alpha_i \tau_i = \theta_0 + \lambda \sum_{i=1}^M \alpha_i (\theta_i - \theta_0) \] 其中 \(\alpha_i\) 为各任务重要性权重，\(\lambda\) 为全局融合缩放系数。模型在不需要联合微调的情况下同时获得 \(M\) 个专家的特长。
  • 负向知识剔除与任务相减（Subtraction / Unlearning）：若某模型 \(\theta_{\mathrm{toxic}}\) 具有极强的攻击性、偏见或毒性生成倾向，我们可以定义有害任务向量 \(\tau_{\mathrm{toxic}} = \theta_{\mathrm{toxic}} - \theta_0\)，并在目标模型中反向扣除： \[ \theta_{\mathrm{clean}} = \theta_{\mathrm{target}} - \gamma \tau_{\mathrm{toxic}} \] 这一运算能够精准抑制特定领域的有害能力，成为机器遗忘（Machine Unlearning）的高效捷径。
  • 类比推理（Analogy）：类似词向量运算（King - Man + Woman = Queen），模型层面也可以进行能力迁移：\(\theta_{\mathrm{new}} = \theta_0 + \tau_{\mathrm{code\_python}} + (\tau_{\mathrm{rust\_annotated}} - \tau_{\mathrm{c\_annotated}})\)。

2.3 球面线性插值（SLERP）

当我们要融合的模型数量恰好为 2 个（例如：一个经过高质量大尺度 SFT 的指令模型 \(\theta_1\)，和一个经过严格 DPO 安全对齐的模型 \(\theta_2\)）时，传统的线性插值（Linear Interpolation, LERP）存在一个内在几何缺陷：高维球体中，线性插值点的模长会发生向心塌陷。

高维参数空间具有极强的各向异性（Anisotropy）和超球面特性。当向量维度 \(d \sim 10^{10}\) 时，两个微调向量主要分布在超球面壳层上。若沿欧氏直线插值 \(\theta_{\mathrm{lerp}} = (1-\alpha)\theta_1 + \alpha \theta_2\)，当 \(\alpha = 0.5\) 且两向量正交时，中间点的欧式模长会剧烈缩短为原来的 \(\frac{\sqrt{2}}{2} \approx 0.707\)。这会导致神经网络隐藏层激活方差失真、输出 Logits 范围收缩、以及温度采样紊乱。

球面线性插值（Spherical Linear Interpolation, SLERP） 解决了这一几何失真问题。SLERP 沿着单位超球面上的测地线（大圆弧）进行匀速角度插值，严格保持向量模长的平滑过渡：

\[ \Omega = \arccos\left(\frac{\theta_1 \cdot \theta_2}{\|\theta_1\| \|\theta_2\|}\right) \] \[ \theta_{\mathrm{slerp}}(\alpha) = \frac{\sin((1 - \alpha)\Omega)}{\sin \Omega} \theta_1 + \frac{\sin(\alpha \Omega)}{\sin \Omega} \theta_2 \]

当两个向量几乎平行（\(\Omega \to 0\)）时，分母趋于零，数值计算自动平滑退化为标准线性 LERP。SLERP 在开源社区模型合并竞赛（如 Open LLM Leaderboard）中被广泛用作打磨最后性能的利器。

本节小结：简单线性加权假设各参数完全同分布且互相独立，在高维空间极易导致模长收缩；SLERP 从球面几何视角修复了二元插值的范数失真。

3. 高阶去噪与冲突消除：Fisher、TIES-Merging 与 DARE

当融合参与者超过两个、或者各模型微调的数据分布存在显著差异时，直接相加任务向量会遭遇严重挫折：参数冲突（Parameter Interference）与信噪比崩溃。本节将拆解现代融合工程的核心去噪算法：Fisher 加权、TIES-Merging 和 DARE。

3.1 权重冲突与符号干扰（Interference and Sign Conflict）

研究表明，当两个模型分别进行微调时，虽然绝大部分参数更新幅度极小（充斥着训练噪声），但有部分高敏感度关键参数在两个任务中的更新方向完全相反。例如：

  • 对于神经元权重 \(W_{i,j}\)，编程任务要求其增大更新：\(\tau_{1, (i,j)} = +0.8\)；
  • 而创意文学写作任务要求其减小更新：\(\tau_{2, (i,j)} = -0.7\)。

如果简单相加：\(\tau_{1} + \tau_{2} = +0.1\)，这两个任务在该参数上的梯度互相抵消。更糟糕的是，成千上万个微弱更新方向随机叠加，导致背景噪声被无谓放大，淹没了真正的关键信号。这种现象被称为 符号干扰（Sign Conflict）与冗余噪声泛滥。

3.2 Fisher 加权合并（Fisher Merging）

并非所有参数的重要性都是均等的。Matena 与 Raffel（2022）引入了 Fisher 信息矩阵（Fisher Information Matrix, FIM） 作为参数重要性加权系数。对于模型 \(\theta_k\)，其对角 Fisher 值为：

\[ F_{k, (i)} = \mathbb{E}_{x \sim \mathcal{D}_k} \left[ \left( \frac{\partial \log p_{\theta_k}(x)}{\partial \theta_{k, (i)}} \right)^2 \right] \]

\(F_{k, (i)}\) 直观反映了参数 \(i\) 的微小扰动对模型预测概率分布产生的曲率影响。Fisher 合并公式为：

\[ \theta_{\mathrm{fisher}, (i)} = \frac{\sum_{k=1}^M F_{k, (i)} \theta_{k, (i)}}{\sum_{k=1}^M F_{k, (i)}} \]

如果参数 \(i\) 在数学模型上具有巨大的 Fisher 曲率，而在代码模型上几乎平坦，则融合后该参数由数学模型主导。虽然 Fisher 合并理论完备，但为数十亿参数计算并存储经验 Fisher 对角阵需要额外的前向反向传播，显存与工程代价较高。

3.3 TIES-Merging（Task Vectors + Trimming + Electing + Scaling）

Yadav 等人（NeurIPS 2023）提出了极具实用价值的 TIES-Merging 算法，在无需重新计算梯度的前提下，纯粹依靠代数规则系统性解决干扰。该算法由三个环环相扣的步骤组成：

  1. 修剪（Trimming）：对于每个任务向量 \(\tau_k\)，仅保留绝对值最大的前 \(p\%\)（例如 \(p=20\%\)）的最重要参数，将其余 \(80\%\) 视作微调噪声直接置零： \[ \hat{\tau}_k = \mathrm{Trim}(\tau_k, p) \]
  2. 符号选举（Electing Signs）：对所有参与融合的模型在特定参数坐标上的更新符号进行全局多数表决（Majority Vote）。确定一个全局多数符号向量 \(\gamma \in \{-1, +1\}^d\)： \[ \gamma_{(j)} = \mathrm{sgn}\left( \sum_{k=1}^M \hat{\tau}_{k, (j)} \right) \] 若某个模型在位置 \(j\) 上的更新符号与全局多数符号相反（即冲突背离），则直接将该模型的该参数置零剔除！
  3. 融合与重缩放（Disjoint Merge & Scaling）：仅对保留下来的同符号参数取平均，并乘以全局缩放系数 \(\lambda\)： \[ \tau_{\mathrm{ties}, (j)} = \lambda \cdot \frac{1}{|K_j|} \sum_{k \in K_j} \hat{\tau}_{k, (j)} \] 其中 \(K_j = \{k \mid \mathrm{sgn}(\hat{\tau}_{k, (j)}) = \gamma_{(j)}\}\)。

3.4 DARE（Drop And REscale）：极简即极致的随机稀疏

Yu 等人（ICLR 2024）提出了令人惊叹的 DARE（Drop And REscale） 算法。作者发现，完全不需要复杂的显著性排序与多数表决，只要以极高概率（高达 90%~99%）随机将任务向量的参数置零，再按留存比例放大，就能近乎奇迹般地消除冲突！

DARE 的数学原理源自蒙特卡洛无偏估计与伯努利掩码：

\[ m_j \sim \mathrm{Bernoulli}(1 - p) \] \[ \tilde{\tau}_{k, (j)} = m_j \cdot \frac{\tau_{k, (j)}}{1 - p} \]

其中 \(p \in (0, 1)\) 是丢弃率（Drop Rate，常设为 0.9）。由于除以了保留概率 \(1 - p\)，掩码操作后的任务向量数学期望严格保持不变：

\[ \mathbb{E}[\tilde{\tau}_{k, (j)}] = (1 - p) \cdot \frac{\tau_{k, (j)}}{1 - p} + p \cdot 0 = \tau_{k, (j)} \]

当多个独立模型的任务向量被随机稀疏化至 10% 甚至 5% 之后，它们在绝大多数参数坐标上的更新相互正交错开（同时在同一坐标非零的概率仅为 \((1-p)^2 \sim 0.01\)），参数冲突与相消现象被自然化解于无形。DARE 与 TIES 结合（DARE-TIES）是目前开源社区公认能力最强悍、鲁棒性最好的融合配方之一。

4. 后训练中的模型融合核心应用范式

在实际大模型研发管线中，模型融合绝非仅仅是打榜刷分的技巧，它已经成为后训练流程中不可或缺的生产力组件。本节提炼工业界后训练中的三大核心融合落地范式。

4.1 范式一：SFT 模型与偏好对齐（DPO/PPO）模型的正交融合

在第 18 章与第 22 章中我们深入探讨过“对齐税（Alignment Tax）”现象：经过高强度 RLHF 或 DPO 对齐后的模型，其安全性和拒绝率显著提高，但在复杂代码生成、逻辑推理和文学创意上的表现往往会发生回退（表现为模型输出风格保守、句式刻板、数学推理链长度缩短）。

通过模型融合可以完美破除这一二元对立：

  • 独立训练一个以追求极致能力上限为目标的 SFT 模型 \(\theta_{\mathrm{sft}}\)（使用包含海量多轮复杂指令、代码、逻辑题的高质量数据，甚至容忍轻微的不安全性）；
  • 独立训练一个以强化安全拒绝、价值对齐与诚实回答为目标的 对齐模型 \(\theta_{\mathrm{align}}\)（使用 DPO 或 PPO 专注于安全边界优化）；
  • 利用 SLERP 或 DARE-TIES，以 \(\alpha \approx 0.6 \sim 0.7\) 的比例对二者进行融合： \[ \theta_{\mathrm{final}} = \mathrm{SLERP}(\theta_{\mathrm{sft}}, \theta_{\mathrm{align}}, \alpha=0.35) \]

实验证明，融合后的模型能够在完全继承 \(\theta_{\mathrm{sft}}\) 强大解题能力的同时，严格遵循 \(\theta_{\mathrm{align}}\) 的安全拒答准则，以近乎零成本的代价消除了绝大部分对齐税。

4.2 范式二：跨领域专家融合（Polymath Merging）

当需要交付一个横跨医疗、金融、代码、多语言的全功能工业模型时，联合训练面临数据配比黑洞：不同领域数据的质量差异、语言词表频率差异以及收敛速度差异极难权衡。现代范式采用“分而治之，合流归一”：

  1. 由四个专项小组基于统一基座分别产出：\(\theta_{\mathrm{code}}\)、\(\theta_{\mathrm{math}}\)、\(\theta_{\mathrm{med}}\)、\(\theta_{\mathrm{fin}}\)；
  2. 通过 DARE 算法对每个专家模型提取稀疏任务向量：\(\tilde{\tau}_{\mathrm{code}}, \tilde{\tau}_{\mathrm{math}}, \tilde{\tau}_{\mathrm{med}}, \tilde{\tau}_{\mathrm{fin}}\)；
  3. 执行 TIES 符号选举合成：在金融和医疗问答上保持专业严谨，在写代码时调用编程专家的突触连接，且最终模型体积完全不变（仍为原本参数量）。

4.3 范式三：Frankenmerge 与 Upcycling（跨层重叠与 MoE 升级）

除了同构模型的横向加权，社区还衍生出了两种激进的纵向与拓扑融合玩法：

  • Frankenmerge（缝合拼接）：将两个不同微调模型的不同 Transformer 层交叉串联。例如将 32 层的 Llama 模型重叠拼接为 48 层或 56 层的深层模型（Pass-through merge），通过复用底层通用语言层与高层特异推理层，实现参数量级的物理扩展。
  • MoE 升级融合（Merge-to-MoE / Upcycling）：将多个稠密（Dense）专家模型的前馈神经网络（FFN）作为混合专家（MoE）的 Expert 分支，新增一个随机初始化的门控路由网络（Gating Router），只需耗费极少量的微调步数训练路由，即可零门槛构建千亿级 MoE 架构。
💡 实践建议：融合超参数的敏感度排序

在实际工程中，参数重要性排序通常为：丢弃率（Drop Rate \(p\)） > 符号表决保留率 > 全局缩放因子（Scaling \(\lambda\)） > 任务间相对权重（\(\alpha_i\)）。当模型出现乱码或严重幻觉时，优先调大 DARE 的丢弃率（例如由 0.8 提升至 0.95），通常能立竿见影地压制噪声。

5.2 核心算法 PyTorch 原生实现：Task Arithmetic 与 DARE-TIES

为了透彻理解其背后的张量操作，我们脱离高阶封装，用原生 PyTorch 实现完整的 DARE-TIES 融合算子。代码严格包含张量掩码、无偏重缩放、符号多数表决与安全融合：

task_merging_ops.py 
import torch
from typing import List, Dict

def dare_mask_and_rescale(task_vector: torch.Tensor, drop_rate: float = 0.9) -> torch.Tensor:
    """
    DARE (Drop And REscale) 核心算子实现
    :param task_vector: 任务向量 (theta_task - theta_base)
    :param drop_rate: 丢弃率 p (0.0 < drop_rate < 1.0)
    :return: 稀疏化且保持数学期望一致的无偏任务向量
    """
    if drop_rate <= 0.0:
        return task_vector
    assert 0.0 < drop_rate < 1.0, "drop_rate 必须在 (0, 1) 区间内"
    
    keep_prob = 1.0 - drop_rate
    # 生成伯努利保留掩码: 1 代表保留，0 代表丢弃
    mask = torch.bernoulli(torch.full_like(task_vector, keep_prob))
    # 伯努利随机丢弃 + 乘以 1/keep_prob 进行幅值无偏重缩放
    scaled_vector = (task_vector * mask) / keep_prob
    return scaled_vector

def ties_sign_election(task_vectors: List[torch.Tensor]) -> torch.Tensor:
    """
    TIES 符号多数表决算子
    :param task_vectors: 各微调模型经过 DARE 处理后的任务向量列表 [V_1, V_2, ..., V_M]
    :return: 多数表决确定的全局符号向量 (-1 或 +1)
    """
    # 堆叠为高维张量 [M, ...]
    stacked = torch.stack(task_vectors, dim=0)
    # 对所有模型在各维度的幅值进行全局求和
    total_sign_mass = torch.sum(stacked, dim=0)
    # 多数符号: >0 为 +1，<0 为 -1，等于 0 默认为 1
    elected_sign = torch.sign(total_sign_mass)
    elected_sign[elected_sign == 0] = 1.0
    return elected_sign

def merge_dare_ties(
    base_state_dict: Dict[str, torch.Tensor],
    task_state_dicts: List[Dict[str, torch.Tensor]],
    weights: List[float],
    drop_rate: float = 0.9,
    global_scale: float = 1.0
) -> Dict[str, torch.Tensor]:
    """
    完备的 DARE-TIES 模型状态字典融合流水线
    :param base_state_dict: 预训练底座权重字典
    :param task_state_dicts: 各专家微调模型权重字典列表
    :param weights: 各专家的加权系数列表 (长度等于 task_state_dicts)
    :param drop_rate: DARE 随机稀疏丢弃率
    :param global_scale: 融合任务向量全局缩放步长 lambda
    :return: 融合完成的目标模型 state_dict
    """
    merged_dict = {}
    num_models = len(task_state_dicts)
    weights_tensor = torch.tensor(weights, dtype=torch.float32)
    weights_tensor = weights_tensor / weights_tensor.sum() # 归一化

    for key in base_state_dict.keys():
        base_param = base_state_dict[key].clone().to(torch.float32)
        
        # 对于分类头、位置编码或形状不一致的非线性参数，直接保留底座参数
        is_linear_param = any(t in key for t in ["weight", "bias"]) and base_param.dim() >= 1
        if not is_linear_param:
            merged_dict[key] = base_state_dict[key]
            continue
            
        # 1. 计算各模型的独立任务向量: tau_i = theta_i - theta_0
        task_vectors = []
        for i in range(num_models):
            param_i = task_state_dicts[i][key].to(torch.float32)
            tau_i = param_i - base_param
            # 2. 执行 DARE 随机丢弃与幅值重缩放
            tau_dared = dare_mask_and_rescale(tau_i, drop_rate=drop_rate)
            task_vectors.append(tau_dared)
            
        # 3. 执行 TIES 符号多数选举
        elected_sign = ties_sign_election(task_vectors)
        
        # 4. 符号过滤与冲突消解: 滤除与大势符号相反的叛逆参数
        filtered_vectors = []
        for i in range(num_models):
            tau = task_vectors[i]
            # 保留同号项，异号项置零
            aligned_mask = (torch.sign(tau) == elected_sign)
            tau_filtered = tau * aligned_mask.to(tau.dtype)
            filtered_vectors.append(tau_filtered * weights_tensor[i])
            
        # 5. 加权合力与基座重构: theta_merge = theta_0 + lambda * sum(filtered_tau)
        combined_tau = torch.stack(filtered_vectors, dim=0).sum(dim=0)
        final_param = base_param + global_scale * combined_tau
        
        # 转换回原始数据精度 (如 bfloat16)
        merged_dict[key] = final_param.to(base_state_dict[key].dtype)
        
    return merged_dict

5.3 自动化融合网格搜索与超参数扫描脚本

import itertools

def grid_search_merging_params():

6. 融合缺陷、干涉机制与工程避坑指南

尽管模型融合在绝大多数公开基准测试中表现惊艳，但它绝非毫无副作用的“免费午餐”。若缺乏对高维权重交互机制的敬畏，工程团队极易掉入破坏性陷阱。

6.1 权重抵消与幻觉激增

最隐蔽的融合缺陷在于“平均化导致的自信度丧失（Loss of Model Confidence）”。当两个对同一专业名词持有不同释义模式的模型被平均后，融合模型在该位置的 Logits 分布平坦化，熵显著增高。反映在生成表现上，模型在短文本基准测试中准确率极高，但在长文本续写与多轮推理时极易陷入语无伦次的循环幻觉或事实捏造。

🚨 严重红线：绝对禁止跨分词器（Tokenizer）直接融合权重

模型融合最常见也是最致命的新手错误是：试图融合两个基于不同 Tokenizer 预训练或微调过的模型（例如试图将原生 LLaMA-2-7B 与修改了词表扩展的中文版 LLaMA-2-Chinese-7B 直接相加）。由于两者的 Embedding 矩阵与最后 lm_head 分类头各行对应的词表 Token ID 发生了乱序错位，直接融合将彻底摧毁神经语言表征，输出 100% 的乱码垃圾字符！

7. 本章小结

  • 理论基石：模型融合之所以成立，是因为共享预训练底座将不同任务的微调限制在同一个平坦凹盆地中，满足线性模式连接（LMC），微调位移可被视作局部切空间的任务向量（Task Vector）。
  • 核心算法谱系：简单线性平均存在模长萎缩与噪声放大的致命缺陷；SLERP 在超球面上维持测地线几何范数；TIES-Merging 通过剪枝、多数符号选举消除抵消；DARE 则以极简的高概率随机置零和无偏重缩放实现惊人的正交去噪。
  • 工程生产力：模型融合是破解“对齐税”与“多任务联合训练梯度冲突”的高性价比解药。借助 MergeKit 编排，只需消费级算力与数分钟 CPU 运算，即可零门槛组合出多领域复合专家大模型。
🧠 自测题（点击展开答案）
问题 1：为什么直接将从不同随机种子独立预训练出的两个 Transformer 模型取权重算术平均会导致性能彻底崩溃？

答案解析：因为深度神经网络具有高度的置换对称性（Permutation Symmetry）。即使两个模型学到了相似的表征，隐藏层各神经元（或注意力头）的排列索引也是完全随机的。直接按对应索引相加，等于将神经元 A 的权重与功能完全不同的神经元 B 混杂相加；更重要的是，非共享初始化的两个模型之间隔着高耸的能量壁垒（\(\epsilon \gg 0\)），不具备线性模式连接条件，直接插值必然落入极高损失的山峦区域。

问题 2：在 SLERP 算法中，为什么比欧几里得线性插值（LERP）更适合用于对齐模型与 SFT 模型的二元融合？

答案解析：高维欧几里得线性插值会导致向量模长向原点塌陷（在中间点模长最小缩减至约 0.707）。在语言模型中，隐藏层权重模长直接决定了激活值的方差和 Logits 的绝对尺度。模长收缩会使得输出概率分布趋于平缓（相当于人为增大了生成温度），引发输出确定性下降与文本幻觉。SLERP 沿着单位超球面的大圆弧执行角度匀速插值，全程严格保持向量模长平滑稳定，杜绝了激活方差失真。

问题 3：DARE 算法中以 90% 的极高概率将参数随机置零，为什么不仅不会损害性能，反而能提升多模型融合的效果？请从数学期望与冲突概率两个角度解答。

答案解析：① 数学期望层面：DARE 对保留下来的参数除以了保留概率 \(1-p\)（即乘上 \(\frac{1}{0.1} = 10\)），根据伯努利随机变量期望性质，被变换后的任务向量数学期望严格等于原始任务向量，因此属于无偏估计；② 冲突概率层面：当两个独立任务向量均被稀疏化至 10% 后，它们在同一参数坐标上同时非零的碰撞概率骤降至 \(10\% \times 10\% = 1\%\)。绝大多数坐标上的更新完全相互正交错开，从根源上消除了符号互冲、梯度抵消与背景噪声干扰。
