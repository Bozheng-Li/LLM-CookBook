第 50 章 · 多模态后训练（Multimodal Post-Training）

当后训练的疆界从单模态文本延伸至图像、视频等多模态高维空间，大语言模型便拥有了观察并理解物理世界的眼睛。多模态后训练不是纯文本微调的简单平移，它面临模态表征对齐、多模态特有幻觉、跨模态偏好冲突以及长上下文图文联合优化的严峻挑战。本章系统解构视觉语言模型（VLM）的核心架构桥接器（Projection Layer, Q-Former, Perceiver）、视觉指令微调（LLaVA 范式）、多模态直接偏好对齐（Multimodal DPO）以及特有幻觉的根治之道，并提供生产级多模态微调与偏好数据工程实现。

1. 从语言到世界：视觉语言模型（VLM）后训练全景图

人类智能的演进绝非建立在纯符号的真空中，我们无时无刻不在通过视觉、听觉与空间知觉与外部物理世界交互。在自然语言后训练技术日臻成熟之后，构建具备“看懂图表、理解视频、解析真实世界场景”的 视觉语言模型（Vision-Language Models, VLM） 成为了迈向具身智能与通用人工智能的必然跃迁。

现代主流开源多模态大模型（如 LLaVA 系列、Qwen2-VL、InternVL）通常遵循模块化解耦的设计范式，将系统拆解为三个核心支柱：

  • 视觉编码器（Vision Encoder）：通常采用在大规模对比图文数据（CLIP / SigLIP）或自监督目标（DINOv2）上预训练好的 ViT（Vision Transformer），负责将二维像素栅格转化为高维连续语义网格向量。
  • 模态桥接适配器（Modality Connector / Projector）：负责将视觉编码器输出的空间特征投影到大语言模型（LLM）的文本 Embedding 维度，充当跨模态翻译的“物理接口”。
  • 大语言模型骨干（LLM Backbone）：作为多模态系统的“中央大脑”，负责进行跨模态上下文自注意力推理、逻辑链推演并自回归生成最终回复。

多模态后训练的本质，就是让原本只精通符号变换的纯文本大脑，学会将视觉投影送来的连续前置序列（Soft Tokens）当成不可或缺的外部语境（Conditioning Prefix），并完成精准的跨模态多步对齐。

2. 模态桥接器深度剖析：从 Linear Projection 到 Q-Former 与 Resampler

在 VLM 的架构设计中，如何将视觉高维特征映射到文本特征空间，决定了计算复杂度、显存占用以及表征表达能力。工业界主流演进出了三类经典桥接器：

2.1 简单多层感知机（MLP Projection Layer）

LLaVA 系列（LLaVA-1.5 / LLaVA-NeXT）以极简哲学著称。它直接采用两层带非线性激活函数的 MLP：

\[ Z_v = W_2 \cdot \mathrm{GELU}(W_1 \cdot H_v + b_1) + b_2 \]

其中 \(H_v \in \mathbb{R}^{N_p \times d_v}\) 为 ViT 输出的视觉 Patch 特征矩阵（\(N_p\) 通常为 576 或 729），\(Z_v \in \mathbb{R}^{N_p \times d_{\mathrm{txt}}}\) 为直接馈入 LLM 的 Soft Token 嵌入。其优点是结构极简、保留全部空间几何拓扑；但缺点是视觉 Token 数量过大（一张图像占满数百个上下文位置），在长文档或多图视频场景下显存迅速爆棚。

2.2 查询转换器（Q-Former / Perceiver Resampler）

BLIP-2 与 Flamingo 引入了基于可学习查询（Learnable Queries）的压缩架构。通过引入一组数量固定的潜在向量 \(Q \in \mathbb{R}^{K \times d}\)（例如 \(K=32\) 或 \(64\)），通过多头交叉注意力（Cross-Attention）从海量视觉特征中抽取最关键的高阶语义信息：

\[ Z_v = \mathrm{CrossAttention}(\mathrm{Query}=Q, \, \mathrm{Key}=H_v, \, \mathrm{Value}=H_v) \]

该机制将数百个视觉 Token 强力无损压缩至数十个，极大减轻了 LLM 的计算负担，但在细粒度 OCR 识别与极微小物体定位（Grounding）上容易丢失空间坐标分辨率。

3. 视觉指令微调（Visual Instruction Tuning）：LLaVA 范式

仅完成模态桥接的预热，模型只能输出呆板的图像粗描述。让模型像人类助手一样回答复杂多图问答、执行多步图文推导的关键，在于 视觉指令微调（Visual Instruction Tuning）。

3.1 多模态指令数据的解耦构建

与纯文本后训练数据类似，多模态指令数据包含三种核心范式：

  • 精细化长文本描述（Detailed Captioning）：要求模型不仅说出图中的核心主体，更要巨细靡遗地描绘背景环境、物体颜色材质、相对空间坐标与场景氛围。
  • 复杂视觉推理（Complex Reasoning）：例如展示一张物理实验示意图，提问：“如果割断左侧滑轮的绳子，右侧的砝码会向上还是向下移动？请分步解释物理原理。”
  • 多轮图文交互（Multi-turn Visual Conversation）：针对同一张图像展开追问（例如：“图中穿红衣服的人手里拿着什么？”→“这个物品在日常生活中有什么用途？”）。

3.2 掩码损失计算机制

在多模态 SFT 中，损失函数必须经过严格的模态与角色掩码隔离：

\[ \mathcal{L}_{\mathrm{V-SFT}}(\theta) = -\sum_{t \in \mathcal{T}_{\mathrm{resp}}} \log P_\theta(y_t \mid Z_v, x_{1:t-1}) \]

注意：视觉 Soft Tokens（\(Z_v\)）以及用户提问 Prompt 对应的 Token 序列，在反向传播时必须通过交叉熵 ignore_index=-100 进行严格掩码屏蔽！我们只要求模型对助手产出的文本 Token 计算自回归梯度，绝不能反向强迫模型去预测图像特征自身。

💡 实践建议：分阶段微调解耦策略（Two-Stage Tuning）

在算力充裕的工业生产中，多模态后训练必须严格分步走：Stage 1 模态特征对齐：完全冻结视觉编码器与 LLM，仅微调中间 Projector（约 500 万参数），使用大规模简单的图像-简短 Caption 数据集（如 CC3M、LAION 过滤子集）；Stage 2 视觉指令精调：冻结 ViT，同时解锁 Projector 与 LLM 骨干（采用全量或 LoRA），使用精选的高质量视觉对话与推理数据集进行多任务优化。

4. 多模态特有幻觉机理与多模态直接偏好对齐（Multimodal DPO）

在纯文本大模型中，幻觉通常表现为事实性捏造；而在视觉语言模型中，幻觉现象呈现出更为诡异、频繁且致命的“多模态特有模式”。

4.1 多模态特有幻觉的三大毒瘤

  1. 主体不存在（Object Hallucination）：图中根本没有任何猫，但模型因为被提问“图中的猫在干什么”，或者由于常见语言共现概率（如看到毛线团就自发补全猫），信誓旦旦地描述猫在打滚。
  2. 属性错位（Attribute Binding Failure）：图中有一个红色的气球和一个蓝色的立方体，模型却输出“一个蓝色的气球和一个红色的立方体”。注意力机制未能将视觉特征中的颜色属性与正确的空间物体绑定。
  3. 空间位置颠倒（Spatial Relationship Inversion）：无法分清左右、前后与包含关系（如将“汽车在桥下”错误理解为“汽车在桥上”）。

导致这一现象的底层根因在于：LLM 骨干的先验语言偏置（Language Prior）极度压倒了微弱的视觉前置特征。如果视觉特征在注意力层中未能提供足够强烈的对数比抑制，语言模型会本能地沿着纯文本的统计概率惯性继续生成。

4.2 多模态直接偏好对齐（Multimodal DPO）

解决多模态幻觉最强有力的工业武器是 多模态直接偏好对齐（Multimodal DPO）。将纯文本 DPO 形式化扩展为以图像视觉嵌入 \(Z_v\) 为前置条件的条件概率比率：

\[ \mathcal{L}_{\mathrm{V-DPO}}(\theta) = -\mathbb{E}_{(v, x, y_w, y_l) \sim \mathcal{D}_{\mathrm{pref}}} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w \mid Z_v, x)}{\pi_{\mathrm{ref}}(y_w \mid Z_v, x)} - \beta \log \frac{\pi_\theta(y_l \mid Z_v, x)}{\pi_{\mathrm{ref}}(y_l \mid Z_v, x)} \right) \right] \]

其中：

  • \(v\) 为原始输入图像，由冻结 ViT 提取并映射为 \(Z_v\)；
  • \(x\) 为视觉提问 Prompt；
  • \(y_w\)（胜者回复）：严格基于图中真实存在的内容，无幻觉、空间定位精准；
  • \(y_l\)（败者回复）：故意诱导或模型自身采样产出的含有“物体不存在、属性张冠李戴”的幻觉回复。

5. 生产级实战：构建 LLaVA 架构的视觉问答指令微调系统

本节将使用 PyTorch 与 Hugging Face 原生生态，完整实现一个兼容 LLaVA 范式的多模态视觉问答指令微调模型核心模块。包含视觉特征投影桥接器、图文张量交错拼接以及带有严密掩码的损失计算。

5.1 模块化多模态因果语言模型实现

vlm_model_arch.py 
import torch
import torch.nn as nn
from transformers import AutoModelForCausalLM, CLIPVisionModel

class MultimodalProjector(nn.Module):
    """
    LLaVA-1.5 风格的两层非线性 MLP 模态投影桥接器
    将 ViT 输出的视觉隐藏维度 d_v 映射为 LLM 的文本词嵌入维度 d_txt
    """
    def __init__(self, visual_dim: int, text_dim: int):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(visual_dim, text_dim),
            nn.GELU(),
            nn.Linear(text_dim, text_dim)
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.mlp(x)

class SimpleLLaVAModel(nn.Module):
    """
    极简端到端多模态视觉大模型封装
    包含：冻结的视觉编码器 + 可训练 MLP Projector + 可训练/LoRA LLM
    """
    def __init__(
        self,
        vision_model_name: str,
        llm_model_name: str,
        image_token_id: int = 32000
    ):
        super().__init__()
        self.image_token_id = image_token_id
        
        # 1. 视觉编码器 (以 CLIP-ViT-L/14 为例)
        self.vision_tower = CLIPVisionModel.from_pretrained(vision_model_name)
        self.vision_tower.requires_grad_(False) # 严格冻结视觉基座
        
        # 2. 模态对齐投影器
        visual_dim = self.vision_tower.config.hidden_size
        
        # 3. LLM 骨干语言模型
        self.language_model = AutoModelForCausalLM.from_pretrained(llm_model_name)
        text_dim = self.language_model.config.hidden_size
        
        self.projector = MultimodalProjector(visual_dim=visual_dim, text_dim=text_dim)

    def encode_images(self, pixel_values: torch.Tensor) -> torch.Tensor:
        """提取图像视觉特征并通过 MLP 投影为 Soft Tokens"""
        with torch.no_grad():
            # 提取 ViT 倒数第二层空间 Patch 特征 [B, num_patches, d_v]
            vision_outputs = self.vision_tower(pixel_values, output_hidden_states=True)
            image_features = vision_outputs.hidden_states[-2][:, 1:, :] # 剔除 CLS token
            
        # 通过投影层转换到文本空间维度 [B, num_patches, d_txt]
        projected_tokens = self.projector(image_features)
        return projected_tokens

    def forward(
        self,
        input_ids: torch.Tensor,
        pixel_values: torch.Tensor = None,
        attention_mask: torch.Tensor = None,
        labels: torch.Tensor = None
    ):
        """
        前向传播：将文本 input_ids 中的  特殊占位符动态替换为视觉 Soft Tokens
        """
        # 获取输入文本的初始 Embedding 向量 [B, seq_len, d_txt]
        inputs_embeds = self.language_model.get_input_embeddings()(input_ids)

        if pixel_values is not None:
            # 投影得到图像特征嵌入 [B, num_patches, d_txt]
            image_embeds = self.encode_images(pixel_values)
            
            # 在实际工程中，此处需执行张量拼接逻辑：
            # 找到 input_ids == self.image_token_id 的位置，将 image_embeds 填充切入
            # 为演示清晰度，此处将视觉 Soft Token 拼接在整个序列的最前端作为前缀
            inputs_embeds = torch.cat([image_embeds, inputs_embeds], dim=1)
            
            if labels is not None:
                # 视觉部分不计算语言模型损失，在 labels 前方填充 -100 忽略标记
                batch_size, num_patches, _ = image_embeds.shape
                image_ignore_mask = torch.full(
                    (batch_size, num_patches), -100, dtype=labels.dtype, device=labels.device
                )
                labels = torch.cat([image_ignore_mask, labels], dim=1)
                
            if attention_mask is not None:
                # 扩展对应的 attention 掩码
                image_attn = torch.ones(
                    (attention_mask.shape[0], image_embeds.shape[1]),
                    dtype=attention_mask.dtype, device=attention_mask.device
                )
                attention_mask = torch.cat([image_attn, attention_mask], dim=1)

        # 馈入 LLM 自回归解码
        outputs = self.language_model(
            inputs_embeds=inputs_embeds,
            attention_mask=attention_mask,
            labels=labels,
            return_dict=True
        )
        return outputs

5.2 视觉指令微调多轮数据流预处理

多模态后训练数据预处理的核心难点是构建严谨的 Token 与 Label 对应关系。以下脚本演示如何将带有图像的图文问答样本构造成适合梯度计算的张量字典：

vqa_data_processor.py 
from typing import Dict, Any, List
import torch

def preprocess_vqa_sample(
    tokenizer,
    prompt_text: str,
    answer_text: str,
    max_length: int = 512,
    image_placeholder: str = "\n"
) -> Dict[str, torch.Tensor]:
    """
    构造单条多模态问答微调数据：严密屏蔽用户 Prompt 与图像区域的梯度
    """
    # 构造标准对话格式
    full_prompt = f"{image_placeholder}User: {prompt_text}\nAssistant: "
    full_conversation = f"{full_prompt}{answer_text}"
    
    # 对提示词部分和完整对话部分分别编码
    prompt_ids = tokenizer.encode(full_prompt, add_special_tokens=False)
    full_ids = tokenizer.encode(full_conversation, add_special_tokens=False)
    
    # 构造训练 Labels: 初始全部置为 -100
    labels = [-100] * len(full_ids)
    
    # 仅将模型真正回答的部分 (Assistant Response) 复制给 labels 用于损失回传
    resp_len = len(full_ids) - len(prompt_ids)
    labels[len(prompt_ids):] = full_ids[len(prompt_ids):]
    
    # 截断与 Padding 处理
    input_ids = full_ids[:max_length]
    labels = labels[:max_length]
    attention_mask = [1] * len(input_ids)
    
    return {
        "input_ids": torch.tensor(input_ids, dtype=torch.long),
        "labels": torch.tensor(labels, dtype=torch.long),
        "attention_mask": torch.tensor(attention_mask, dtype=torch.long)
    }

5.3 多模态 DPO 偏好数据对齐训练核心循环

在获得了图像及胜负回复对 \((v, x, y_w, y_l)\) 后，多模态 DPO 通过比较策略模型与参考模型在带图上下文下的概率偏置，抑制视觉幻觉输出：

train_multimodal_dpo.py 
import torch
import torch.nn.functional as F

def compute_multimodal_dpo_loss(
    model: SimpleLLaVAModel,
    ref_model: SimpleLLaVAModel,
    pixel_values: torch.Tensor,
    win_input_ids: torch.Tensor,
    win_labels: torch.Tensor,
    lose_input_ids: torch.Tensor,
    lose_labels: torch.Tensor,
    beta: float = 0.1
) -> torch.Tensor:
    """
    计算基于图像前置的多模态 DPO 损失算子
    """
    # 1. 策略模型分别前向计算胜者与败者样本的损失
    win_out = model(input_ids=win_input_ids, pixel_values=pixel_values, labels=win_labels)
    lose_out = model(input_ids=lose_input_ids, pixel_values=pixel_values, labels=lose_labels)
    
    # 提取序列负对数似然 (NLL Loss 即为负的 log P(y|Z_v, x))
    pi_win_logp = -win_out.loss
    pi_lose_logp = -lose_out.loss
    
    # 2. 参考模型前向计算 (完全冻结无梯度)
    with torch.no_grad():
        ref_win_out = ref_model(input_ids=win_input_ids, pixel_values=pixel_values, labels=win_labels)
        ref_lose_out = ref_model(input_ids=lose_input_ids, pixel_values=pixel_values, labels=lose_labels)
        ref_win_logp = -ref_win_out.loss
        ref_lose_logp = -ref_lose_out.loss
        
    # 3. 构造 DPO 隐式偏好边际
    pi_log_ratio = pi_win_logp - pi_lose_logp
    ref_log_ratio = ref_win_logp - ref_lose_logp
    margin = beta * (pi_log_ratio - ref_log_ratio)
    
    # 4. 优化目标: -log sigmoid(margin)
    loss = -F.logsigmoid(margin).mean()
    return loss

本节小结：多模态工程的核心在于“坐标与掩码的严丝合缝”：无论是 SFT 还是 DPO，唯有将视觉 Soft Token 严格置于自回归掩码之外，才能引导 LLM 建立正确的跨模态语义因果依赖。

6. 本章小结

  • 系统解耦三件套：视觉大模型由预训练视觉编码器（ViT）、模态适配桥接器（MLP / Q-Former）与 LLM 语言大脑有机统一，后训练核心在于打通跨模态表征翻译并调校因果注意力。
  • LLaVA 范式与二阶段训练：第一阶段冻结两端仅微调投影器完成特征对齐，第二阶段解锁 LLM 骨干进行高分辨率视觉问答与图文长链推理微调，是性价比极高的工业实践。
  • 多模态幻觉治理：视觉幻觉（物体不存在、属性错位）源于强语言先验对弱视觉特征的碾压；多模态 DPO 是压制语言自负偏见、校准空间绑定关系的治本之道。
🧠 自测题（点击展开答案）
问题 1：在对视觉语言模型进行视觉指令微调（SFT）时，为什么必须对输入图像所对应的视觉 Soft Tokens 的损失进行掩码（Mask）屏蔽？

答案解析：在后训练中，模型的目标是学习“给定图像与指令，自回归预测高质量文本回复”的条件概率 \(P(Y_{\mathrm{text}} \mid Z_v, X_{\mathrm{prompt}})\)。图像特征是由高阶 ViT 前向生成的连续向量，大语言模型的分类头（lm_head）是针对离散文本词表的 Softmax。如果对视觉 Soft Token 计算交叉熵损失，一方面属于毫无意义的语法乱码拟合，另一方面会产生剧烈的错误梯度，彻底破坏预训练好的文本语义表征体系。

问题 2：相较于两层 MLP 投影层，Q-Former 桥接架构在细粒度 OCR 识别与极微小目标空间定位上为什么往往表现逊色？

答案解析：两层 MLP 保持了 1:1 的视觉 Patch 空间对齐映射，原始图像网格中每个 14×14 局部切片的空间相对坐标得以完整保留。而 Q-Former 依靠数十个固定可学习查询向量通过交叉注意力抽取高阶语义，本质上是将数百个空间网格强力压缩坍塌为少量全局语义摘要。在这一重度信息瓶颈下，微小的文字笔画和高频边缘坐标细节被作为冗余噪声滤除，导致小文字 OCR 与微小物体边界框（Bounding Box）预测精度显著下滑。

问题 3：在多模态直接偏好对齐（Multimodal DPO）中，如果将参考模型 \(\pi_{\mathrm{ref}}\) 替换为纯文本版本的语言模型（即不输入图像），会发生什么严重偏差？

答案解析：DPO 损失依赖参考模型的基准对数似然比作为隐式正则项，以防止策略模型偏离原始分布。如果参考模型缺失了视觉前置输入，它给出的对数似然仅代表纯文本无条件生成的先验分布，无法衡量“在当前具体图像约束下回复是否合理”。策略模型为了最小化相对差距，会倾向于生成与图像完全脱节但纯文本流畅度极高的通用套话，导致模型进一步无视图像，多模态幻觉不降反升。
