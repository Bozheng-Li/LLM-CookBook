效率与部署

把模型真正跑起来还要跑得快:从权重压缩、推测解码,到 PD 分离、KV 分级与端侧落地。

本篇共 7 个知识点进阶 3 · 高级 4。左侧可按难度筛选。
01 量化、剪枝与模型压缩 PTQ / QAT、GPTQ / AWQ、KV 量化与 1.58bit 极限压缩,以及结构化 / 非结构化剪枝在真实硬件上的收益边界。这是压缩的「不改能力只改表示」一路,靠换小模型继承能力的另一路见 distillation 高级 02 推理引擎 vLLM / SGLang / TensorRT-LLM 的调度、批处理与选型对比 进阶 03 服务化与推理经济学 SLO 设计、吞吐 - 延迟 - 成本三角,以及 token 价格下探与算力供给的产业约束。与 cost-engineering 的分工一句话:效率篇讲怎么让它快,运维篇讲怎么让它不烧钱 进阶 04 推测解码 草稿模型、Medusa、EAGLE 与自推测的加速比分析 高级 05 PD 分离与大规模专家并行部署 Prefill-Decode 分离部署、专家并行 EP 与 EPLB 负载均衡如何压低单 token 成本 高级 06 KV 分级存储与卸载 HBM / DRAM / SSD 三级 KV 缓存、跨请求复用与缓存命中率优化,承接 kv-cache 的显存瓶颈 高级 07 端侧部署与小模型 SLM 小模型能力边界、手机 / PC 端推理栈与端云协同分工 进阶
