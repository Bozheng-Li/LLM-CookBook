GPU 与算子系统

从数学公式到真实硬件:显存层级怎么用、算力怎么核算、kernel 怎么写。本篇为可选深入篇,只想会用大模型的读者可直接跳至预训练篇,需要时再回看。

本篇共 4 个知识点进阶 2 · 高级 2。左侧可按难度筛选。
01 GPU 执行模型与显存层级 SM / warp / HBM / SRAM 的层级结构,以及算力墙与带宽墙从何而来 进阶 02 FLOP、显存核算与性能剖析 手算一个模型的参数量、训练 FLOP、激活值显存与通信量,做预算的基本功;再用 Roofline 与算术强度判断瓶颈落在计算还是访存,配合 profiler 定位真实热点 进阶 03 FlashAttention 与 IO 感知注意力 分块 softmax、重计算与 IO 复杂度分析,FlashAttention 1/2/3 的演进;并讲清什么条件下会静默回退到标准实现(head_dim、dtype、mask 类型、硬件代次),以及如何验证后端真的生效 高级 04 Triton Kernel 与编译优化 用 Triton 写第一个融合算子,理解 tile、block 与内存访问模式;再延伸到 torch.compile、CUDA Graph 与图级算子融合如何消除访存和 kernel 启动开销 高级
权威延伸资料

围绕“GPU 与算子系统”继续深入

本章把模型公式连接到真实硬件：GPU 的执行和内存层级、FLOP 与带宽核算、FlashAttention 的 IO 优化，以及 Triton kernel 的工程方法。

阅读提示：性能问题先判断是算力受限还是访存受限，再用 profiler 和小规模 benchmark 验证；不要把峰值 FLOP 当成实际吞吐。

  • 论文Dao et al. · NeurIPS 2022
    FlashAttention: Fast and Memory-Efficient Exact Attention ↗

    分块、online softmax 和重计算的原始论文，完整解释“IO 感知”为什么能在不近似的情况下加速。

  • 官方文档NVIDIA
    CUDA C++ Programming Guide ↗

    warp、线程块、共享内存、全局内存和同步语义的权威参考，核对 GPU 章节中的硬件事实。

  • 官方指南NVIDIA
    CUDA C++ Best Practices Guide ↗

    合并访存、occupancy、bank conflict 和性能分析的工程清单，适合配合 profiler 使用。

  • 官方教程OpenAI Triton
    Triton Tutorials ↗

    从向量加法、矩阵乘法到融合 kernel 的渐进式教程，是实战页面的直接延伸。

  • 论文Williams et al. · CACM 2009
    Roofline: An Insightful Visual Performance Model ↗

    用算术强度把计算瓶颈和带宽瓶颈放在同一张图上，是性能剖析的经典框架。
