05 篇

GPU 与算子系统

从数学公式到真实硬件:显存层级怎么用、算力怎么核算、kernel 怎么写。本篇为可选深入篇,只想会用大模型的读者可直接跳至预训练篇,需要时再回看。

本篇共 4 个知识点进阶 2 · 高级 2。左侧可按难度筛选。
01 GPU 执行模型与显存层级 SM / warp / HBM / SRAM 的层级结构,以及算力墙与带宽墙从何而来 进阶 02 FLOP、显存核算与性能剖析 手算一个模型的参数量、训练 FLOP、激活值显存与通信量,做预算的基本功;再用 Roofline 与算术强度判断瓶颈落在计算还是访存,配合 profiler 定位真实热点 进阶 03 FlashAttention 与 IO 感知注意力 分块 softmax、重计算与 IO 复杂度分析,FlashAttention 1/2/3 的演进;并讲清什么条件下会静默回退到标准实现(head_dim、dtype、mask 类型、硬件代次),以及如何验证后端真的生效 高级 04 Triton Kernel 与编译优化 用 Triton 写第一个融合算子,理解 tile、block 与内存访问模式;再延伸到 torch.compile、CUDA Graph 与图级算子融合如何消除访存和 kernel 启动开销 高级
