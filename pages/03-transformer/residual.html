入门

残差连接与深层稳定

为什么 ResNet 之前网络堆到二三十层就训不动，而今天的 Transformer 可以轻松到上百层？答案藏在一个极其简单的设计里：残差连接——给梯度一条"绕过"每层的直通通道。它是一行加法，却撑起了整个深度学习时代。这一节把这行加法拆到底：它在数学上做了什么、在工程上有哪些坑、以及如何用 20 行代码亲眼看见梯度消失。

一图看懂

残差连接做的事一句话：把每层的输出改成"输入 + 这层的变换"，而不是"只有这层的变换"。这样哪怕这层学不到有用的东西（变换接近零），信息也能原封不动地通过"输入"这条捷径传到下一层。就像给每层楼装一部直通电梯——住几楼都不影响你直接走到一楼。

深层网络的致命问题：梯度消失

在残差连接出现之前，网络越深效果越好——但只到一个临界点。超过二三十层后，网络不仅不提升，反而变差。根本原因是梯度消失。

反向传播用链式法则把损失对参数的梯度层层传递。对一个 $L$ 层的网络，第一层的梯度是 $L$ 个雅可比矩阵的连乘：

$$\frac{\partial \mathcal{L}}{\partial \mathbf{x}_0} = \frac{\partial \mathcal{L}}{\partial \mathbf{x}_L} \cdot \prod_{l=1}^{L} \frac{\partial \mathbf{x}_l}{\partial \mathbf{x}_{l-1}}$$

如果每个 $\frac{\partial \mathbf{x}_l}{\partial \mathbf{x}_{l-1}}$ 的范数平均小于 1（这很常见，因为激活函数如 ReLU/Sigmoid 会压缩梯度），连乘 $L$ 次后梯度就指数级趋近于 0——第一层几乎收不到学习信号。反之，如果平均大于 1，梯度就会指数级爆炸，训练直接发散。

"指数级"三个字很抽象，代进数字就非常直观了。假设每层雅可比范数是一个固定值 $\rho$，那么第一层收到的梯度大约被缩放了 $\rho^L$ 倍：

注意最关键的一点：$\rho$ 只要不是精确等于 1，深度一上去就必然走向两个极端之一。而让每一层的雅可比范数都恰好等于 1，靠调初始化和学习率是做不到的——它是一个不稳定的平衡点。残差连接的价值就在于：它不是"把 $\rho$ 调到 1 附近"，而是从结构上强行给每层的雅可比加了一个单位矩阵。

关键认知 梯度消失不是"梯度变成精确的零"，而是"经过层层连乘后数值小到浮点精度无法表示"。FP32 的最小正常数约 $1.2 \times 10^{-38}$，一个范数 0.9 的雅可比连乘 400 次就到了 $10^{-19}$ 量级——梯度虽在，但已经小到对参数更新毫无意义。在 FP16 下更早失效：FP16 的最小正常数约 $6.1 \times 10^{-5}$，一个 0.9 的雅可比连乘 100 次就已经掉到这个量级以下，直接下溢为零。这也是混合精度训练要配 loss scaling 的原因之一。

它不是过拟合，这一点很容易搞混

深层网络退化最容易被误判成"参数太多、过拟合了"。但 ResNet 论文里的关键实验恰恰否定了这个解释：在同一份数据上分别训练一个 20 层和一个 56 层的普通卷积网络（没有残差），结果 56 层网络的训练误差也比 20 层更高。

训练误差更高意味着模型连训练集都拟合不了，这跟过拟合是反过来的。逻辑上，56 层网络完全可以把多出来的 36 层学成恒等映射，从而至少复现 20 层的表现——但优化器就是找不到这个解。所以问题出在"优化"而不是"容量"。残差连接干的事，就是把"学成恒等映射"这件事从"很难学到"变成"默认状态"。

残差连接：给梯度一条高速公路

2015 年，何恺明等人在 ResNet 论文里提出了一个极其简单的改动：把每层的输出从 $\mathbf{y} = F(\mathbf{x})$ 改成：

$$\mathbf{y} = \mathbf{x} + F(\mathbf{x})$$

$F(\mathbf{x})$ 是这层的变换（在 Transformer 里就是注意力或 FFN）。多出来的那个 $\mathbf{x}$ 就是残差连接（也叫 shortcut / skip connection）。它让信息有两条路可走：经过 $F$ 变换，或者直接通过 $\mathbf{x}$ 绕过去。

这个改动对梯度的影响是决定性的。对 $\mathbf{y} = \mathbf{x} + F(\mathbf{x})$ 求导：

$$\frac{\partial \mathbf{y}}{\partial \mathbf{x}} = \mathbf{I} + \frac{\partial F(\mathbf{x})}{\partial \mathbf{x}}$$

这里的 $\mathbf{I}$ 是单位矩阵——不管 $\frac{\partial F}{\partial \mathbf{x}}$ 有多小，加上 $\mathbf{I}$ 后总有一份原样的梯度会穿过去。梯度不再需要通过 $F$ 的雅可比矩阵才能传回去，它有一条"加 1"的直通通道。100 层也好，1000 层也好，都存在一条乘积项全为 $\mathbf{I}$ 的路径，把梯度原封不动地送回第一层。

手把手读 ResNet 论文原图

残差连接的第一手出处，是 2015 年何恺明等人的 ResNet 论文《Deep Residual Learning for Image Recognition》。论文 Figure 2 画的就是那个著名的「残差学习块」——整个深度学习史被引用最多的结构图之一。它只有一条主分支和一条捷径，但把「学残差」这件事讲得清清楚楚。

逐块读这张图，一共四个元素。第一块，左上角的输入 $\mathbf{x}$：它是这一层的输入向量，也是后面那条捷径的起点。第二块，中间的主分支：$\mathbf{x}$ 向下依次经过「权重层 → ReLU → 权重层」，这段变换在论文里记作 $F(\mathbf{x})$——对应到 Transformer，就是注意力或 FFN 子层。第三块，右侧那条标着 identity 的虚线捷径（shortcut）：它把 $\mathbf{x}$ 原封不动地绕开主分支，直接引到右下角的 $\oplus$ 求和处。注意捷径上没有任何可学习参数，所以它不增加参数量，也正因为它是恒等映射，梯度穿过它时不会被缩放。第四块，右下角的加法器：$F(\mathbf{x})$ 与 $\mathbf{x}$ 在这里逐元素相加，得到 $\mathbf{y} = F(\mathbf{x}) + \mathbf{x}$，再加一个 ReLU 作为这层的输出。

把这张图和上一节的梯度推导对照看，逻辑完全闭合：捷径给梯度提供了一条「不必穿过 $F$」的回传通道，主分支负责学「还差多少」，捷径负责「原样保底」。图里那句「identity」正是全图的灵魂——正因为捷径是恒等映射而非可学变换，深层训练才从「很难」变成「默认可行」。而图的右侧通常还有一条带注释的虚线标注：当输入输出维度不一致时（比如通道数减半的过渡层），捷径需要换成 $1\times1$ 卷积做投影——这就是本页后面要讲的「投影残差」。

新手最容易搞错 看到 $\mathbf{y} = \mathbf{x} + F(\mathbf{x})$ 里的「$+$」，有人会误以为残差是把两层网络「并联」起来——不对，主分支 $F$ 依然是串联依赖在 $\mathbf{x}$ 上的，只是输出时额外加了一份原始输入。另一个高频误解是把残差和归一化混为一谈：残差管的是「梯度直通」，归一化管的是「数值幅度」，两个解决的是不同问题。最后一个常见错误是维度——加法是逐元素向量加法，要求 $\mathbf{x}$ 与 $F(\mathbf{x})$ 维度完全一致，不一致时必须先做投影残差对齐，否则就是形状报错或静默的错位相加。
踩坑实录：残差分支初始化过大，训练第一步就 NaN

一个典型的翻车过程：搭建深层 Transformer 时沿用了默认的线性层初始化，残差分支（注意力输出投影、FFN 输出投影）用常见的 Xavier / 均匀分布初始化，结果训练开始几百步，loss 直接变成 NaN，怎么调学习率都救不回来。

原因要回到残差的前向累加上去看。残差让 $N$ 层各自往残差流上加一份增量，如果每份增量的标准差是 $s$，$N$ 层之后总方差的量级就是 $\sqrt{N}\,s$。层数一多、初始化又偏大，深层的激活值很快就会涨到溢出的边缘，再叠上 FP16 的低精度范围，一轮反向传播就能把数值推到无穷。

正确的修法通常按严重程度分三步：最轻的是加 warmup 或调小学习率；更彻底的是对残差分支的输出投影做缩小初始化——GPT-2 的做法是按 $1/\sqrt{N}$ 缩放，让 $N$ 层累加后方差回到 $O(1)$；最稳的是把残差分支最后一层权重初始化为零（zero-init），让训练从严格恒等映射 $\mathbf{y}=\mathbf{x}$ 出发，再慢慢学增量。排查时先用「逐层激活 RMS 曲线」确认是哪一层先爆的，再对症下药。

这个坑的教训是：残差虽然给梯度开了绿灯，但也把前向的累加风险转嫁给了初始化——所以「深度 + 残差」的架构里，初始化策略不是细节，而是稳定性的一部分。

把这条路径在时间轴上走一遍会更清楚。下面这张时序图模拟一次反向传播：损失从最后一层往回传，每经过一个 Block，梯度都会"分叉"成两份——一份钻进子层被缩放，一份沿残差通路原样继续往前。

一句话直觉 没有残差连接时，梯度像走楼梯——每下一层都要经过一道门，门太小（雅可比矩阵压缩）就走不过去了。有了残差连接，梯度像坐电梯——不管中间楼层怎么设计，总能直达。

动手：20 行代码看见梯度消失

这一节的所有说法都可以自己验证。下面的脚本搭两个结构完全一样、只差一个加号的 32 层网络，各跑一次反向传播，然后打印第 1 层权重的梯度范数。

import torch
import torch.nn as nn

D, L = 64, 32          # 隐藏维度、层数

class Block(nn.Module):
    def __init__(self, residual):
        super().__init__()
        self.residual = residual
        self.fc = nn.Linear(D, D)
        self.act = nn.Tanh()          # tanh 的导数最大只有 1，天然会压缩梯度

    def forward(self, x):
        out = self.act(self.fc(x))
        return x + out if self.residual else out

def grad_norm_of_first_layer(residual):
    torch.manual_seed(0)
    net = nn.Sequential(*[Block(residual) for _ in range(L)])
    x = torch.randn(8, D)
    net(x).pow(2).mean().backward()   # 随便造一个标量损失
    return net[0].fc.weight.grad.norm().item()

print("plain   :", grad_norm_of_first_layer(residual=False))
print("residual:", grad_norm_of_first_layer(residual=True))

运行后你会看到：plain 网络第 1 层的梯度范数比 residual 网络小好几个数量级（具体倍数取决于随机种子和维度，但差距是稳定存在的）。把 L 从 32 改成 8 再跑一次，差距会明显缩小——这正好印证了"深度越大，差距越悬殊"。这个实验只有几十行，却是理解残差最快的路径：与其记结论，不如亲眼看到那几个数量级的差别。

进一步玩法 把 nn.Tanh() 换成 nn.ReLU()，把 L 拉到 100，再在每个 Block 里加一个 nn.LayerNorm(D) 试试。你会发现归一化能缓解一部分数值失控，但只有残差能真正保住浅层的梯度——这两件事解决的不是同一个问题，详见 归一化技术。

残差在 Transformer 中的具体形态

Transformer 的每个 Block 有两个子层，每个子层都包了一条残差连接。以 Pre-Norm 架构为例（现代大模型标配）：

$$\mathbf{x}_{out} = \mathbf{x} + \text{SubLayer}\!\left(\text{Norm}(\mathbf{x})\right)$$

注意力子层和 FFN 子层各做一次这样的操作。所以一个 Transformer Block 的完整前向是：

$$\mathbf{h} = \mathbf{x} + \text{Attn}\!\left(\text{Norm}_1(\mathbf{x})\right)$$ $$\mathbf{y} = \mathbf{h} + \text{FFN}\!\left(\text{Norm}_2(\mathbf{h})\right)$$

残差连接（$\mathbf{x} + \dots$）和归一化（Norm）的配合关系决定了深层可训练性，详见 归一化技术 一节对 Pre-Norm vs Post-Norm 的分析。关键在于：残差通路（那个直接加的 $\mathbf{x}$）上不能有归一化的除法阻断，这就是 Pre-Norm 比 Post-Norm 更适合深层的根本原因。

残差流：把整个模型看成一条总线

有一个视角能极大地简化对 Transformer 的理解——把所有残差连接串起来看，它们其实是同一条贯穿全模型的向量通道，通常叫作残差流（residual stream）。每个注意力头和每个 FFN 都不是"接在流水线上的一环"，而是从这条总线上读一份数据、算完之后再把结果加回总线。

这个视角有三个直接好处。第一，它解释了为什么各层维度必须全部等于 $d_{model}$——大家读写的是同一条总线，位宽当然要一致。第二，它解释了为什么可以做层剪枝：删掉某一层只是少了一次"加法写入"，总线本身还在，模型不会崩，顶多质量下降。第三，它是可解释性研究的基础工具——研究者可以把最终 logits 拆成"每个注意力头往总线上写了多少贡献"，从而定位某个能力具体由哪几个头负责。

残差连接让网络学"差量"而非"全量"

除了稳定梯度，残差连接还有一个深层影响：它改变了网络学习的内容。

没有残差时，每层要直接学出目标表示 $\mathbf{y} = F(\mathbf{x})$——从零开始构造完整答案。有残差时，每层只需学 $\mathbf{y} - \mathbf{x} = F(\mathbf{x})$——也就是在输入基础上需要修正多少。这就像改作文：直接重写一篇（全量）比在原文上批注修改（差量）难得多。

当网络已经足够好、某层不需要做太多修正时，$F(\mathbf{x})$ 可以自然地学到接近零——这层的输出几乎等于输入，相当于"跳过"了这层。这种恒等映射的易学性让额外加的深层不会"帮倒忙"，网络深度可以放心增加。

无残差：学全量

每层要从头构造完整表示。深层时初始状态差，学起来难，容易越学越偏。想"什么都不做"反而需要精确学出一个单位映射，代价极高。

有残差：学差量

每层只学"在输入基础上改多少"。不需要改时把权重压到接近零即可，深层网络不会"帮倒忙"，加层的边际风险接近零。

工程细节：三个真实会踩的坑

坑一：维度不匹配与投影残差

残差连接要求 $\mathbf{x}$ 和 $F(\mathbf{x})$ 维度相同才能相加。在大多数 Transformer Block 内部，注意力子层的输入输出维度一致，FFN 也是如此，直接相加即可。

但当维度发生变化时（比如通道数减半的过渡层），需要一条投影残差（projection shortcut）：用一个线性变换 $W_s$ 把 $\mathbf{x}$ 的维度对齐到 $F(\mathbf{x})$，即 $\mathbf{y} = W_s \mathbf{x} + F(\mathbf{x})$。在标准 Transformer 里，这通常出现在嵌入层到第一层、以及最后一层到输出头的过渡处。

常见坑 投影残差的初始化要小心。如果 $W_s$ 初始化得太大，残差通路上的信号会被放大，破坏梯度稳定性。实践中常用零初始化让残差分支初期接近恒等映射——让网络先"能训起来"，再慢慢学有用的变换。不少现代架构会把残差分支的最后一层权重初始化为零，确保初始时 $\mathbf{y} = \mathbf{x}$，训练从恒等映射出发。

坑二：残差分支的初始化缩放

残差解决了梯度消失，但带来一个新问题：前向数值会随深度累加。每一层往残差流上加一份方差大致相当的增量，$N$ 层之后残差流的方差大致是初始值的 $N$ 倍——这会让深层的激活值越来越大，配合 Pre-Norm 时表现为"深层的子层贡献被 Norm 压得越来越小"。

常见的缓解办法是按深度缩小残差分支输出投影的初始化。GPT-2 的做法是把残差层的权重初始化按 $1/\sqrt{N}$ 缩放（$N$ 为残差层数量），让 $N$ 层累加后的方差回到 $O(1)$。DeepNet 则给出了另一条路线：给残差通路加一个与深度相关的常数系数 $\alpha$，即 $\mathbf{y} = \alpha\mathbf{x} + F(\mathbf{x})$，据此把 Transformer 稳定地堆到了 1000 层。

坑三：混合精度下的残差累加

这是训练框架层面最容易被忽略的一点。在 FP16/BF16 混合精度训练中，如果残差加法直接用低精度做，深层累加的舍入误差会不断放大——尤其 BF16 只有 8 位尾数，一个大数加一个小数时小数可能被整个吃掉。实践中框架通常把残差流保持在 FP32，只让矩阵乘法走低精度。相关细节见 混合精度训练 与 训练稳定性与优化器。

残差家族与深层稳定技术全景

残差不是凭空出现的，它有前身，也有后续的一整套改良。理清这条线，能帮你看懂各种论文里五花八门的"某某 Norm + 某某 Init"组合到底在解决什么。

残差连接与模型容量的关系

残差连接不只是"稳定训练"的工程技巧，它深刻改变了模型的容量结构。有研究表明，残差网络可以被理解为多个不同深度子网络的隐式集成——因为有残差捷径，信号可以选择在任何一层"跳出去"，相当于同时训练了从浅到深的多种路径。这解释了为什么深层残差网络即使参数量不大幅增加，效果也能持续提升。

在 Transformer 中，这种特性意味着一个 100 层的模型并不强制使用全部 100 层——简单模式可能只"走"几十层，复杂模式才走完全程。这种自适应深度是残差连接带来的意外礼物，也是早退（early exit）类推理加速方法能够成立的前提。

展开：为什么说残差网络是"$2^L$ 条路径的集成"

把两层残差网络完全展开来看。第一层 $\mathbf{x}_1 = \mathbf{x}_0 + F_1(\mathbf{x}_0)$，第二层：

$$\mathbf{x}_2 = \mathbf{x}_1 + F_2(\mathbf{x}_1) = \mathbf{x}_0 + F_1(\mathbf{x}_0) + F_2\big(\mathbf{x}_0 + F_1(\mathbf{x}_0)\big)$$

展开后一共出现了四种"路径"：什么都不过（$\mathbf{x}_0$）、只过 $F_1$、只过 $F_2$、两个都过。每增加一层，路径数就翻一倍——$L$ 层残差网络展开后共有 $2^L$ 条从输入到输出的通路。

这带来两个推论。其一，这些路径的长度分布集中在中等长度附近（服从二项分布），真正"走满全程"的路径只有 $1/2^L$ 的权重，所以有效深度远小于名义深度——这也是"残差网络表现得像浅网络集成"这一说法的来源。其二，删掉某一层只是砍掉了一半路径，剩下的一半仍然完整，所以残差网络对层删除表现出很强的鲁棒性；而普通串行网络删一层就直接断了。

需要注意，"集成"是一个解释性的类比而不是严格定义——这些路径共享参数，并不是真正独立的模型。但它对理解"为什么加层几乎无害"很有帮助。

展开：Pre-Norm 下梯度直通性的一行推导

Pre-Norm 的第 $l$ 层是 $\mathbf{x}_{l} = \mathbf{x}_{l-1} + F_l(\text{Norm}(\mathbf{x}_{l-1}))$。对输入求导：

$$\frac{\partial \mathbf{x}_{l}}{\partial \mathbf{x}_{l-1}} = \mathbf{I} + \frac{\partial F_l}{\partial \mathbf{x}_{l-1}}$$

从第 $L$ 层回传到第 0 层，梯度是这些项的连乘：$\prod_{l=1}^{L}\left(\mathbf{I} + \partial F_l\right)$。把它展开，其中必然包含一项是所有因子都取 $\mathbf{I}$ 的乘积，即 $\mathbf{I}$ 本身——这一项与深度无关，永远不衰减。

再看 Post-Norm：$\mathbf{x}_l = \text{Norm}(\mathbf{x}_{l-1} + F_l(\mathbf{x}_{l-1}))$。求导后每一层都多乘了一个 Norm 的雅可比 $\partial\text{Norm}$，连乘式变成 $\prod_l \partial\text{Norm}_l\left(\mathbf{I} + \partial F_l\right)$。由于 $\partial\text{Norm}$ 的范数通常小于 1（它本质上是一个除以标准差的操作），那条"纯 $\mathbf{I}$"的干净路径就被污染了，深度一大依然会衰减。

这就是 Pre-Norm 与 Post-Norm 差异的数学本质：不在于归一化算得好不好，而在于残差通路上有没有多乘东西。

要点速查

  • 本质：把每层输出改成 $\mathbf{x} + F(\mathbf{x})$，给信息和梯度一条绕过子层的直通通道。额外参数量为 0。
  • 解决的核心问题：深层网络的梯度消失——残差让雅可比里多出一个 $\mathbf{I}$，存在一条永不衰减的回传路径。
  • 不是过拟合问题：无残差的深层网络连训练误差都更高，说明瓶颈在优化而非容量。
  • 学习内容的变化：从学"全量表示"变成学"差量修正"，恒等映射成为易学的默认值，深层不会帮倒忙。
  • 残差流视角：所有残差串起来是一条贯穿全模型的总线，各子层只负责读取和写回增量——这也是层剪枝和可解释性分析的基础。
  • 与归一化的配合：Pre-Norm 保证残差通路上无归一化阻断，是百层以上 Transformer 的必要条件。
  • 关键数字：雅可比范数 0.9 时，100 层后梯度衰减到 $10^{-5}$ 量级；FP16 下 100 层左右就会直接下溢为零。
  • 常见坑：维度不匹配时需要投影残差；投影权重初始化过大破坏稳定性；深层要按 $1/\sqrt{N}$ 缩放残差分支初始化；混合精度下残差流应保持 FP32。

发展脉络

残差连接让深层网络保留恒等路径；与 Pre-Norm、残差缩放和并行分支结合后，成为控制梯度与激活传播的主干。

机制抓手

主路径保持 x，子层只学习增量 f(norm(x))；反向传播包含恒等项，使梯度不必完全穿过每个非线性子层。

工程权衡

残差过强会让深层块贡献变小，增量过大又会造成激活漂移；dropout、缩放和 dtype 会改变平衡。

前沿观察

DeepNorm、ReZero、并行 attention/FFN 和层级缩放继续探索超深模型稳定性，但需与初始化和 norm 联合分析。
