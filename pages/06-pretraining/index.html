06 篇

预训练

从零把一个基座模型训出来:目标函数、真实与合成数据、规模律、并行策略与稳定性。合成数据编排在本篇而不在后训练篇,是因为后训练篇九条统一在「训练算法」这一个维度上,插入数据方法论会破坏维度一致性;放在这里与 data-engineering 构成「真实语料 + 合成语料」的并列对子。

本篇共 9 个知识点进阶 5 · 高级 4。左侧可按难度筛选。
01 预训练目标 CLM / MLM / MTP 与去噪目标的取舍 进阶 02 数据工程 Common Crawl 抽取、质量过滤、去重、数据配比与课程设计 —— 真实语料这一路 进阶 03 合成数据与数据飞轮 承接 data-engineering 的另一路:self-instruct / evol-instruct、拒绝采样微调 RFT、教师模型蒸馏采样与 persona 驱动多样性,配套质量过滤和去污染;这套方法论横跨 sft、grpo-rlvr 与 Agent 训练。反面必须写:模型坍缩与合成数据自污染 进阶 04 Scaling Laws Kaplan / Chinchilla 规模律、算力最优配比与外推方法 高级 05 并行策略：5D 并行的原理与组合 数据 / 流水线 / 张量 / 序列 / 专家五种并行的原理与组合:各自的通信模式、显存-带宽权衡,以及何时叠加、如何计算等效并行度;开箱即用的框架实现(把哪几种并行封装成配置项、显存-通信权衡如何落到参数上)见 training-frameworks 高级 06 训练框架与工程实现 五种并行的原理与组合见 distributed-training;本条讲 ZeRO / FSDP / Megatron-LM / torchtitan 的分工与选型:各自把哪几种并行做成了开箱能力、显存-通信权衡如何体现在配置项上、以及从单机脚本迁移到千卡集群时真正会踩的坑 高级 07 混合精度与显存优化 BF16 / FP8 训练、梯度检查点与显存换算力的各种手段 进阶 08 训练稳定性与优化器 loss spike 排查、梯度裁剪与 Muon 等新一代优化器 高级 09 持续预训练与领域适配 在已有基座上继续训练:领域注入、语言扩展、词表扩充与灾难性遗忘的抑制 进阶
