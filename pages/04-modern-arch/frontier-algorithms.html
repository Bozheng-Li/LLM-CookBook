大模型核心算法：从 Transformer 到 DeepSeek

用计算、显存和训练目标解释现代架构。

MoE 路由

路由器给每个 token 的 expert 打分，top-2 后加权求和。若 token 都去同一个 expert，all-to-all 通信和负载不均会吞掉稀疏收益；Switch 的负载损失、capacity factor 和 dropless routing 必须一起理解。DeepSeek-V3 的 shared expert 与细粒度 expert 是工程取舍，不是免费容量。

GQA、MLA 与 KV Cache

GQA 让多个 query head 共享 K/V，直接减少 cache 头数；MLA 先把 K/V 压到 latent，再按需恢复表示，减少每 token 存储维度。前者是头共享，后者是低秩压缩。评测必须报告 cache bytes/token 和 decode 吞吐。

MTP 与推理时扩展

多 token 预测让草稿模型一次提出更长候选串，再由主模型并行验收；验收率低或 batch 小时可能反而变慢。DeepSeek-V3/R1 把 MTP、RLVR 和 test-time sampling 组合，训练扩容和推理扩容必须用质量-延迟-成本曲线选择。

新人练习

给定32层、4096长度、8个KV head、head_dim=128、BF16，计算 KV cache 字节数，再比较 MHA、GQA 和 MLA 的变化。
