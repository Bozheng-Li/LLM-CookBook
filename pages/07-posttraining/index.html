后训练与对齐

把基座变成可用的助手和推理器。本篇九条统一在「训练算法」这一个维度上:指令微调、偏好对齐、可验证奖励强化学习与能力迁移组合。

本篇共 9 个知识点入门 1 · 进阶 5 · 高级 3。左侧可按难度筛选。
01 SFT 监督微调 指令数据构造、对话模板设计与训练配方,以及数据质量优先于数量的经验规律;数据本身怎么造出来见 synthetic-data 入门 02 RLHF 奖励模型训练、PPO 流程与人类反馈闭环 —— ChatGPT 之所以是 ChatGPT 的关键一步。RL 概念不熟先看 rl-basics 高级 03 参数高效微调 LoRA / QLoRA / DoRA 的低秩假设、秩选择与工程实践 进阶 04 免奖励模型对齐 DPO / IPO / KTO / SimPO 如何绕开显式奖励模型 进阶 05 推理强化学习 GRPO / GSPO / DAPO 与可验证奖励 RLVR 如何训出长思维链;并正面处理 reward hacking —— 模型钻奖励函数空子拿到高分却没真正解决问题,如何识别、如何在奖励设计上缓解 高级 06 对齐税与安全对齐 有用性与无害性的权衡、Constitutional AI 与拒答校准。这是安全四方里的训练侧:把安全烙进权重。执行侧见 agent-safety,运行时组件侧见 guardrails,攻方与测评侧见 safety-redteam 进阶 07 Agentic RL 与多步决策训练 承接 grpo-rlvr,假定已掌握优势估计与 KL 约束。从单步 MDP 到多步 POMDP:轨迹级信用分配、环境交互采样与分布式 RL 系统。与 agent 一条的分工是:本条讲怎么训一个 Agent,agent 讲怎么搭一个 Agent 高级 08 知识蒸馏与能力迁移 响应 / 特征 / 思维链蒸馏的统一视角,兼顾能力继承与部署压缩两种目的;换小模型继承能力这一路在此,不改能力只改表示那一路见 quantization 进阶 09 模型融合与能力组合 Model Soup、Task Arithmetic、TIES、DARE 如何免训练地组合多个微调模型 进阶
