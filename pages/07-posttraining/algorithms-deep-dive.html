后训练算法：从示范到可验证推理

面向新人的推导、手算例子和实验方法。

先建立直觉

预训练让模型会续写；SFT 教它按格式回答；DPO 教它在两个答案中选择；RLVR 用程序检查答案是否真的正确。三种信号不能互换。

SFT 的 loss mask

对“用户：17乘3。助手：51”只给助手 token 计算交叉熵，用户 token 的 label 设为 -100。漏掉 EOS 会导致模型不停止，模板不一致会导致训练和推理错位。

DPO 手算

DPO logit = beta * ((log pi(y+) - log ref(y+)) - (log pi(y-) - log ref(y-)))。若两个 margin 是 0.8 和 0.2，beta=0.1，则 logit=0.06，loss=-log(sigmoid(0.06))约为0.663。margin 过大时梯度趋近零，脏偏好数据会让模型“很快学完”。

GRPO/RLVR 手算

同题采样四次，验证器得分 [1,1,0,1]，均值0.75；正确答案优势0.25，错误答案优势-0.75。全对或全错时组内优势为零，所以课程学习要维持适中通过率。DeepSeekMath 首次系统化 GRPO，DeepSeek-R1 将冷启动 SFT、RLVR、拒绝采样组合。

工程实验

每个 checkpoint 固定运行格式合规率、任务成功率、KL、长度和成本；验证器先用人工正确样本校准，再开 RL。发现 reward hacking 时先修 verifier 和数据，不要只调学习率。
