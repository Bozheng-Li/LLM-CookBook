# 量化：把权重变小

量化把模型权重从 fp16 降到 int8 或 int4，直接换取显存和带宽。解码阶段是访存受限的，权重搬得少，速度就快。

训练后量化（PTQ）不需要重新训练。GPTQ 逐层求解一个最小化重构误差的问题，用少量校准数据即可。AWQ 观察到少数「显著通道」承担了绝大部分精度损失，对这些通道做缩放保护，其余正常量化。两者在 4bit 下通常能把困惑度损失控制在 0.1 以内。

量化感知训练（QAT）在训练时就插入伪量化算子，让模型提前适应精度损失，效果更好但成本高得多，通常只在需要压到 2bit 或 3bit 时才考虑。

需要区分三个东西：权重量化、激活量化和 KV Cache 量化。它们的难度依次递增——激活值有离群点，动态范围大得多，int8 激活量化往往需要 SmoothQuant 这类把量化难度从激活转移到权重的技巧。

一个反直觉的结论是：4bit 的大模型通常优于 fp16 的小模型。同样的显存预算下，先选大模型再量化，而不是选小模型保精度。
