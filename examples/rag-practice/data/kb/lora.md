# LoRA 与参数高效微调

LoRA 冻结原始权重 W，只训练一个低秩增量 BA，其中 B 是 d×r、A 是 r×k，r 远小于 d 和 k。前向变成 `Wx + (BA)x × alpha/r`。可训练参数量通常只有全量微调的 0.1% 到 1%。

省显存主要不是省在参数本身，而是省在优化器状态。AdamW 为每个可训练参数维护一阶和二阶动量，加上梯度，全量微调时这部分是权重的三倍。冻结主干后，这三份开销随可训练参数一起缩小。

秩 r 的选择有一条经验：任务越接近预训练分布，r 可以越小。学习一种输出格式，r=8 通常够；注入新领域知识，r 要提到 64 甚至 128，而且效果往往不如继续预训练。

target_modules 决定低秩补丁加在哪些层。只加 q_proj 和 v_proj 是最省的配置，但 QLoRA 论文的消融显示，把所有线性层都加上（含 k_proj、o_proj 和 MLP 的三个投影）在同等可训练参数预算下效果更好。

QLoRA 把主干量化到 4bit 再挂 LoRA，让单卡 24 GB 能微调 33B 模型。它引入了 NF4 数据类型、双重量化和分页优化器三个技巧，其中 NF4 针对正态分布权重设计，比普通 int4 更省精度。
