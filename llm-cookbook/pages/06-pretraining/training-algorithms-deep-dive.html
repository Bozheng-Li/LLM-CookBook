预训练算法：目标函数、数据混合与稳定性

从 next-token loss 出发，把数据、优化器、并行和验证连成一个可复现的训练闭环。

1. 目标函数不是一句“预测下一个词”

因果语言模型最小化 L=-Σ_t m_t log p_θ(x_t|x_<t)，其中 mask m_t 决定哪些 token 计入损失。padding、文档边界和 packing 若处理错误，会把无意义 token 当监督信号。训练日志至少分开记录各数据源 loss、有效 token 数和 padding 比例。

2. 数据混合：token 配额与梯度信号

多个数据集按比例 q_i 采样时，真正的更新权重还受序列长度、重复率和 loss 难度影响。可用温度采样 q_i∝p_i^α，但 α 不是质量旋钮：它改变的是梯度出现频率。每个 checkpoint 做 held-out loss、去重命中率和领域切片评估，避免“总 loss 下降”掩盖某一领域退化。

3. 优化器与学习率

AdamW 的更新为 m_t=β₁m+...; v_t=β₂v+...; θ←θ-η m̂/(√v̂+ε)-ηλθ。warmup 防止初始大梯度破坏预训练表示，余弦衰减控制后期步长。梯度累积时要按有效 token 归一化；混合长度 batch 若直接按样本平均，会让短序列被过度加权。

4. 稳定性：先诊断，再调参

现象优先检查修复顺序
loss 突然 NaN溢出、数据异常、通信不同步fp32 归约、梯度裁剪、跳过坏 batch
loss 平台且梯度小学习率、mask、重复数据小范围扫 η，核对有效 token
训练降而验证升污染、重复、领域比例去重、扩大 held-out、调混合

5. 并行不是算法之外的事

数据并行复制参数，张量并行切矩阵，流水线并行切层；通信量与拓扑会改变有效 batch 和吞吐。每次改并行配置都记录 MFU、通信占比、bubble、激活峰值和 checkpoint 一致性。一个理论 FLOP 估算若没有 profiler 校准，不足以支持容量决策。

6. 最小可复现实验

在 1B 以下模型上固定 3 个数据源，运行 1B、3B、10B 有效 token 的短程实验；对比 α、warmup 比例和 packing。保存配置、数据快照 hash、随机种子、每 100 step 的分片 loss 与梯度范数。用相同 token 预算比较，而不是比较 wall-clock。

发展脉络

预训练从 CLM/MLM 目标扩展到多 token 预测、课程数据和合成数据，训练规模则由 Kaplan 经验律推进到 Chinchilla 的计算最优配比。

机制抓手

把数据去重、混合比例、token 预算、并行策略、checkpoint 和验证集视为同一个实验设计，而不是互相独立的脚本参数。

工程权衡

更多数据、更多参数和更长训练之间需要按计算预算平衡；数据污染、重复和合成数据坍缩会让离线 loss 失真。

前沿观察

持续预训练、数据飞轮、MTP、FP8 和新优化器仍在发展，必须报告数据谱系和消融实验。

实践检查能从 token 预算估算训练 FLOP、显存和并行策略，并设计 loss spike、数据泄漏和 checkpoint 恢复的排查流程。

学习目标

能联合分析目标函数、token 配比、学习率、稳定性与并行策略，而不是把它们当成互不相关的配置项。

先修关系

先修语言模型目标、反向传播和优化器；把 token 预算、数据版本和 checkpoint 视为实验输入。

最小实验

在微型语料上做 2x2 消融：两种数据配比乘两种学习率，固定 token 预算和模型；记录各域 loss、梯度范数、tokens/s、有效 token 与 checkpoint。

验收标准

四组实验除目标变量外配置一致，结果表含均值和至少 3 个种子；能据此选择配方，并写出停止、回滚和扩大规模前的门槛。
