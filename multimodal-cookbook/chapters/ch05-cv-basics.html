1.卷积网络简史：2012 年的那个秋天

卷积神经网络（Convolutional Neural Network, CNN）不是 2012 年的发明——LeCun 等人在 1989–1998 年就用 LeNet-5 完成了银行支票数字识别（1998 年《Proceedings of the IEEE》论文，约 6 万参数，卷积+下采样+全连接的骨架与现代 CNN 一致）。真正改变历史的是 2012 年 9 月 30 日：Krizhevsky、Sutskever 与 Hinton 的 AlexNet 在 ImageNet ILSVRC-2012 竞赛中把 top-5 错误率从上一年的 25.8% 一举压到 15.3%（第二名 26.2%），领先幅度史无前例。图像分类从此进入了"深度学习十年"。

AlexNet 的胜利要素今天看都是"常识"：ReLU 激活（比 tanh 快数倍）、Dropout 正则、两块 GTX 580 GPU 上 6 天训练（模型 6000 万参数——当年需要在两卡间手工切分网络）、大规模数据（ILSVRC 120 万张、1000 类）。此后是三步快跑：VGG（2014，arXiv:1409.1556）证明"更小卷积核堆更深"的简单美学（全部 3×3 卷积，16–19 层，1.38 亿参数）；GoogLeNet/Inception（2014，arXiv:1404.5997）用 1×1 卷积做瓶颈、多尺度并行卷积，把参数量压到 680 万的同时拿到 6.7% top-5；ResNet（2015，arXiv:1512.03385）用残差连接把深度推到 152 层、ensemble top-5 错误率 3.57%——首次超越人类水平（约 5.1%），并包揽当年 ImageNet 检测、定位、COCO 检测/分割冠军。

🕰 历史一刻：2012–2015，三年换了三次天

2012 年 AlexNet（15.3%）证明了"深度+数据+GPU"的路线；2013 年 ZFNet（11.7%）靠反卷积可视化解释了卷积在"看什么"；2014 年 VGG（7.3%）与 GoogLeNet（6.7%）把深度推到 19 层与 22 层；2015 年 ResNet（3.57%）解决了"深度堆不动"的根本问题。如果算上检测线的节奏——R-CNN（2014）→ Fast R-CNN（2015）→ Faster R-CNN（2015）→ YOLO（2016）→ Mask R-CNN（2017）——你会发现 2012–2017 这五年奠定了今天所有视觉系统（包括 VLM 的视觉塔与 grounding 头）的地基。2017 年 Transformer 问世，2019 年 ViT 的前身们开始出现，2020 年 ViT 发布——CNN 的黄金十年结束，但它留下的工程遗产（残差、归一化、增强、预训练→微调范式）全部被继承。

2.卷积的数学与归纳偏置

卷积层做的事情：一个可学习的核（kernel）在输入特征图上滑动，每个位置做一次加权求和。对输入 $\mathbf{X}\in\mathbb{R}^{C_{in}\times H\times W}$ 与核 $\mathbf{W}\in\mathbb{R}^{C_{out}\times C_{in}\times k\times k}$，输出通道 $o$ 在位置 $(i,j)$ 处：

$$\mathbf{Y}_{o,i,j} = \sum_{c=1}^{C_{in}}\sum_{u=1}^{k}\sum_{v=1}^{k} \mathbf{W}_{o,c,u,v}\cdot \mathbf{X}_{c,\; i\cdot s+u-1,\; j\cdot s+v-1} + b_o$$

其中 $s$ 是步幅（stride）。与全连接层对比，卷积有三条"先天约束"，统称归纳偏置（Inductive Bias）：（1）局部性——每个输出只看 $k\times k$ 的邻域（像素的语义是局部的）；（2）参数共享——同一个核扫过全图（2024×2024 参数即可覆盖任意尺寸输入，而全连接需要输入尺寸 × 输出尺寸）；（3）平移等变性——把输入平移一格，输出特征图相应平移一格（数学上：$T_\delta \mathrm{Conv}(\mathbf{X}) = \mathrm{Conv}(T_\delta \mathbf{X})$，因为核与位置无关）。加上池化带来的近似平移不变性与逐层堆叠产生的层级结构（边缘→纹理→部件→物体），CNN 把"视觉世界的先验"直接焊进了架构。

感受野（Receptive Field）是量化"每层看多远"的核心概念：第 $l$ 层一个输出神经元的感受野为

$$RF_l = RF_{l-1} + (k_l - 1)\times\prod_{i=1}^{l-1} s_i$$

推导直觉：第 $l$ 层的每个输出位置读 $k_l$ 个上一层位置，而每个上一层位置已经"看过" $RF_{l-1}$ 宽的输入；两层之间的距离被中间各层的步幅 $s_i$ 放大。举例：VGG-16 的三个 3×3 卷积（stride 1）串联，$RF = 1+2+2+2 = 7$——恰好等于一个 7×7 卷积，但用了 3 次 ReLU（3 个非线性）与三分之一的参数（$3\times(3^2)=27$ vs $49$），这就是"小核堆叠"优于大核的原因。

python
import torch
import torch.nn as nn
import torch.nn.functional as F

# —— 手写 2D 卷积前向（教学用；生产用 nn.Conv2d，其内部走 cuDNN/tensor core）——
def conv2d_naive(x, weight, bias=None, stride=1):
    """x: [B, Cin, H, W]，weight: [Cout, Cin, k, k]"""
    B, Cin, H, W = x.shape
    Cout, _, k, _ = weight.shape
    Ho, Wo = (H - k) // stride + 1, (W - k) // stride + 1
    # im2col 思想：把每个滑动窗口展开成列，卷积变成一次矩阵乘 —— GPU 上卷积的真实形态
    cols = F.unfold(x, kernel_size=k, stride=stride)          # [B, Cin*k*k, Ho*Wo]
    w = weight.view(Cout, -1)                                  # [Cout, Cin*k*k]
    out = w @ cols                                             # [B?] 等价批量矩阵乘
    out = out.view(1, Cout, Ho, Wo) if B == 1 else out         # 简化演示（仅 batch=1）
    return out + (bias.view(1, -1, 1, 1) if bias is not None else 0)

x = torch.randn(1, 3, 32, 32)
w = torch.randn(8, 3, 3, 3)
mine = conv2d_naive(x, w)
ref = F.conv2d(x, w)
print("与 F.conv2d 的最大误差:", (mine - ref).abs().max().item())   # ≈1e-6

# —— 感受野计算器：输入 (kernel, stride, dilation) 的逐层列表 ——
def receptive_field(layers):
    rf, jump = 1, 1                      # jump：相邻两个输出位置对应的输入距离
    for k, s, dil in layers:
        k_eff = dil * (k - 1) + 1        # 膨胀卷积的有效核
        rf = rf + (k_eff - 1) * jump
        jump = jump * s
    return rf

vgg_style = [(3,1,1)] * 3               # 三个 3×3、stride 1
print("三个 3×3 的感受野:", receptive_field(vgg_style))              # 7
resnet_stem = [(7,2,1), (3,2,1)] + [(3,1,1)] * 3
print("ResNet 前 5 层的感受野:", receptive_field(resnet_stem))        # 27

3.ResNet 与残差学习：完整推导

2015 年之前，"加深网络"遇到一个反直觉的墙：在 CIFAR-10 上，56 层普通卷积网络的训练误差反而高于 20 层版本——这不是过拟合（过拟合是训练误差低、测试误差高），而是优化问题：更深的普通网络连"恒等映射"这个理论上最简单的解都学不到（多层非线性把 $\mathbf{x}\mapsto\mathbf{x}$ 变成了难以拟合的目标）。He 等人（ResNet，CVPR 2016 最佳论文，arXiv:1512.03385）的解法只有一行公式——把要学的映射从目标 $\mathcal{H}(\mathbf{x})$ 改写为相对恒等的残差 $\mathcal{F}(\mathbf{x}) = \mathcal{H}(\mathbf{x}) - \mathbf{x}$：

$$\mathbf{y} = \mathcal{F}(\mathbf{x}, \{W_i\}) + \mathbf{x} \qquad \text{（维度不匹配时以线性投影 } \mathbf{W}_s\mathbf{x} \text{ 替换 } \mathbf{x})$$

直觉：如果某个层"最好什么都不做"，只要把 $\mathcal{F}$ 推向 0 即可（权重衰减天然干这事），而"恒等"对非线性层堆来说是难的、对"加法直通"来说是免费的。

📐 理论推导：残差连接为什么让百层网络可训练

第一步：多块嵌套展开。记第 $l$ 个残差块的输入为 $\mathbf{x}_l$，块函数 $\mathcal{F}_l$，则 $\mathbf{x}_{l+1} = \mathbf{x}_l + \mathcal{F}(\mathbf{x}_l, W_l)$。对任意深的块链（从 $l$ 到 $L$）反复代入：

$$\mathbf{x}_{L} = \mathbf{x}_{l} + \sum_{i=l}^{L-1}\mathcal{F}(\mathbf{x}_i, W_i)$$

深层的特征 $\mathbf{x}_L$ 永远以加法包含着浅层特征 $\mathbf{x}_l$——信息有一条不经过任何权重矩阵的直通路径。

第二步：梯度公式。对损失 $\mathcal{E}$ 求梯度，用链式法则（$\partial \mathbf{x}_L / \partial \mathbf{x}_l$ 经上式对 $\mathbf{x}_l$ 求导）：

$$\frac{\partial \mathcal{E}}{\partial \mathbf{x}_l} = \frac{\partial \mathcal{E}}{\partial \mathbf{x}_{L}}\cdot\left(1 + \frac{\partial}{\partial \mathbf{x}_l}\sum_{i=l}^{L-1}\mathcal{F}(\mathbf{x}_i, W_i)\right)$$

关键在括号里的 "1 +"：梯度中永远有一项直接以系数 1 从 $\mathbf{x}_L$ 传回 $\mathbf{x}_l$——不管网络多深、不管中间的 $\mathcal{F}$ 导数多小，乘法链条上多了一个加法的"逃生通道"，梯度消失的指数衰减被彻底打断。对照普通网络：$\frac{\partial \mathcal{E}}{\partial \mathbf{x}_l} = \frac{\partial \mathcal{E}}{\partial \mathbf{x}_L}\cdot\prod_i \frac{\partial \mathbf{x}_{i+1}}{\partial \mathbf{x}_i}$，连乘中每项 $<1$ 就是指数消失、$>1$ 就是爆炸——残差把"乘法链"变成了"乘法 + 加法"的混合结构。

第三步：为什么训练初期尤其友好。随机初始化时 $\mathcal{F}$ 输出很小，每个块近似恒等映射——网络从"一条干净的信息直通线"出发，逐步学"改写量"。这与第 3 章 Pre-LN Transformer 的"残差流"是同一个数学骨架：LLaMA 式块 $\mathbf{x}_{l+1} = \mathbf{x}_l + \mathrm{Attn}(\cdot) + \mathrm{FFN}(\cdot)$ 就是 ResNet 公式的两连击。

第四步：两个补充视角。（1）隐式集成（Veit et al., arXiv:1605.06431）：展开递推后 ResNet 等价于 $2^{L}$ 条"不同深度子网"路径的集合，删除单个块不致命（实验：随机跳块测试误差几乎不变），解释了它对深度扰动的鲁棒性。（2）Pre-Activation 版本（He et al., arXiv:1603.05027）：把 BN/ReLU 移到卷积之前（$\mathbf{y} = \mathbf{x} + F(\mathrm{BN}(\mathrm{ReLU}(\mathbf{x})))$），让"恒等路径"上完全没有任何变换，千亿级深度的训练更平滑；它也是后来 Transformer Pre-LN 设计的直接灵感来源。$\blacksquare$

python
import torch
import torch.nn as nn

class BasicBlock(nn.Module):
    """ResNet-18/34 的基本残差块（Post-activation 原始形态）"""
    expansion = 1
    def __init__(self, cin, cout, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(cin, cout, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(cout)
        self.conv2 = nn.Conv2d(cout, cout, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(cout)
        # 下采样或通道变化时，捷径用 1×1 卷积 + BN 匹配维度（即公式中的 W_s）
        self.shortcut = nn.Sequential()
        if stride != 1 or cin != cout:
            self.shortcut = nn.Sequential(
                nn.Conv2d(cin, cout, 1, stride, bias=False), nn.BatchNorm2d(cout))

    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))     # F 的前半
        out = self.bn2(self.conv2(out))                # F 的后半（ReLU 留到相加后）
        return torch.relu(out + self.shortcut(x))      # y = ReLU( F(x) + W_s·x )

block = BasicBlock(64, 128, stride=2)
x = torch.randn(2, 64, 56, 56)
print(block(x).shape)              # [2, 128, 28, 28]：分辨率减半、通道翻倍（VGG 式惯例）

# 验证残差梯度公式的"1 + ∂F/∂x"：数值检查恒等路径确实传梯度
x = torch.randn(1, 4, 8, 8, requires_grad=True)
y = x + torch.nn.Sequential(nn.Conv2d(4, 4, 3, padding=1))(x)     # 最小残差块
y.sum().backward()
print("输入梯度范数:", x.grad.norm().item())   # 与纯恒等(≈y.sum 的 1.0)同量级：直通成立

4.BatchNorm、数据增强与训练技巧

BatchNorm（批量归一化，Ioffe & Szegedy, ICML 2015，arXiv:1502.03167）是让"深 CNN + 大学习率"成为现实的第二根支柱。对每个通道 $c$，在一个 batch 的所有样本与所有空间位置上统计均值与方差，再做仿射归一化：

$$\hat{x}_{c} = \frac{x_c - \mu_{\mathcal{B},c}}{\sqrt{\sigma^2_{\mathcal{B},c}+\epsilon}}, \qquad y_c = \gamma_c\,\hat{x}_c + \beta_c, \qquad \mu_{\mathcal{B},c} = \frac{1}{m}\sum_{\mathcal{B}} x_c$$

$\gamma,\beta$ 是可学习的缩放/平移（归一化不破坏表达力）。训练与推理行为不同：训练用当前 batch 的统计量（且同步维护指数滑动平均的 running mean/var，动量常取 0.1）；推理切换为固定的 running 统计量（model.eval()）。原论文把收益归因于缓解"内部协变量偏移"（Internal Covariate Shift），Santurkar 等（arXiv:1805.11604）后来的分析指出更本质的作用是让损失面更平滑（Lipschitz 常数变小），从而容忍更大学习率。与第 3 章的 LayerNorm 相比：BN 依赖 batch 且有训练/推理差异，在序列/Transformer 语境下被 LN/RMSNorm 全面取代；但在 CNN 里 BN 至今仍是默认（ConvNeXt 等现代 CNN 也在用 LN，属于少数派）。分布式训练时大 batch 被切到多卡，单卡统计失真，需要 SyncBN 跨卡同步。

python
import torch
import torch.nn as nn

bn = nn.BatchNorm2d(4, momentum=0.1)      # 4 个通道
x_train = torch.randn(8, 4, 16, 16)

bn.train()                                 # 训练模式：用 batch 统计量
out = bn(x_train)
print("训练输出均值≈0:", out.mean(dim=(0, 2, 3)).tolist())   # 各通道 ≈0
print("running_mean 仍在累积:", bn.running_mean.abs().sum().item() > 0)

bn.eval()                                  # 推理模式：切到 running 统计量（固定）
out2 = bn(x_train)
print("eval 模式下同批输入输出不变:", torch.allclose(bn(x_train), out2))

# 经典 bug：训练/评估模式没切换 —— dropout 与 BN 的行为不同，
# 表现为"训练 loss 正常，验证指标莫名变差"或"BN 统计被验证集污染"
model = nn.Sequential(nn.Conv2d(3, 8, 3, padding=1), nn.BatchNorm2d(8))
model.train()   # 忘记调用 model.eval() 是练习生最常见的翻车点

数据增强与经典训练配方。CNN 时代沉淀的增强组合至今仍在视觉预训练里服役：随机裁剪+水平翻转（基本盘）、颜色抖动、Random Erasing；Mixup（arXiv:1710.09412，把两张图按 $\tilde{x}=\lambda x_i + (1-\lambda)x_j$、标签同理线性混合，$\lambda\sim\mathrm{Beta}(\alpha,\alpha)$）与 CutMix（arXiv:1905.04899，把一块矩形区域贴到另一张图、标签按面积加权）显著改善校准与泛化；标签平滑（label smoothing 0.1）在 Transformer 原论文里也已被采用。多模态时代的传承：VLM 训练里视觉塔若参与训练，增强必须谨慎（文本标签与视觉内容强对齐时，过强的增强反而破坏对齐，第 16、35 章展开）；而 SAM/DINOv2 的训练配方仍大量使用这些技术。

💡 技巧：CNN 微调的三条旧船票

（1）判别式学习率：预训练层用 1/10 的学习率、新分类头用全量学习率——这正是第 1 章配方表"视觉塔 0.1η"的出处。（2）冻结 BN：小 batch 微调时冻结 BN 的 running 统计量（module.eval() 只作用于 BN 层），否则统计漂移会毁掉预训练特征。（3）先看 baseline：换任何 fancy 增强前，先跑一遍"裁剪+翻转"的朴素配方——ImageNet 级任务上朴素配方的收敛曲线往往已经接近上限。

5.检测与分割一页通

分类只回答"图里有什么"，检测与分割回答"在哪里、什么形状"——这两个能力对多模态模型至关重要：VLM 输出 bounding box（Kosmos-2/Shikra 一系，第 21 章）、自动构造 grounding 数据（第 34 章）、SAM 驱动的像素级编辑（第 26 章），全部建立在检测/分割的概念与词汇之上。一页速览三大谱系：

两阶段检测（Region-based）：R-CNN（2014，选择性搜索提候选框 + CNN 逐框分类）→ Fast R-CNN（整图一次提特征，RoI Pooling 取特征）→ Faster R-CNN（Ren et al., NeurIPS 2015，arXiv:1506.01497）：用区域建议网络（Region Proposal Network, RPN）替代外部候选算法——在共享卷积特征上滑动小网络，对每个位置输出 $k$ 个 anchor（默认 3 尺度 × 3 长宽比）的"是否含物体"分数与框回归。端到端可训练，VGG 版约 5 FPS、PASCAL VOC07 mAP 73.2，成为此后五年的检测基座。单阶段检测：YOLO（Redmon et al., CVPR 2016，arXiv:1506.02640）把检测变成"网格回归"——$7\times7$ 网格每个格子直接预测框与类别，45 FPS（Fast YOLO 155 FPS）开启实时检测，精度略逊（VOC07 mAP 63.4）；SSD（arXiv:1512.02325）多尺度特征图并行预测；RetinaNet（arXiv:1708.02002）用 focal loss 解决正负样本极端不平衡，让单阶段追平两阶段。分割：语义分割（FCN，arXiv:1411.4038，全卷积逐像素分类）→ 实例分割 Mask R-CNN（He et al., ICCV 2017 最佳论文，arXiv:1703.06870）：在 Faster R-CNN 上加一个逐 RoI 的小型分割分支，并把 RoI Pooling 换成 RoIAlign——用双线性插值消除取整量化误差（对像素级任务致命），COCO 上实例分割提升明显。全景分割（panoptic）把"stuff"（天空、路面）与"things"（可数物体）统一到一张标签图。

6.ViT 前史与归纳偏置之争

Transformer 在 NLP 统一之后，视觉侧的"叛变"分三步走。第一步：验证 Transformer 能不能直接看图。iGPT（Chen et al., ICML 2020，arXiv:1906.00462）把 32×32 低分辨率图像的像素按光栅顺序展开成序列、用 GPT 式自回归预训练——证明了纯 Transformer 无需卷积也能学出高质量视觉表示，但代价巨大（13 亿参数的 iGPT-L 在小数据下的线性探测精度不及同规模 CNN），结论是"方向对、性价比不对"。第二步：ViT 用数据规模翻案。Dosovitskiy 等人（ICLR 2021，arXiv:2010.11929）把图像切成 16×16 patch、线性投影成 token 序列（加上 [CLS] token 与位置编码，第 2 章 patch embedding 的出处），用标准 Transformer 编码器做图像分类：在 ImageNet-1k 上 ViT 不如同级 CNN，但预训练数据扩到 JFT-300M（3 亿图）后反超——ViT-H/14 达 88.55% top-1，且同等质量下所需计算量远小于 CNN。

第三步：弥合样本效率差距。ViT 在中等数据下也能打，靠两条路。蒸馏：DEiT（Touvron et al., ICML 2021，arXiv:2012.12877）证明仅用 ImageNet-1k 训练 ViT 是可行的，配方是强增强 + 稳定训练，以及一个关键的蒸馏 token——序列里额外放一个可学习 token，其注意力目标指向一个训练好的 CNN teacher（如 RegNetY）的 logits，DEiT-B 蒸馏后达 83.4% top-1（约 +2 点），且蒸馏 token 的注意力图呈现出与 [CLS] 不同的全局关注模式。层级化：Swin Transformer（Liu et al., ICCV 2021 最佳论文，arXiv:2103.14030）把 Transformer 拉回"特征图金字塔"的世界——patch 合并逐级下采样（4×→8×→16×），注意力限制在滑动窗口内、隔层移位（shifted window）实现跨窗通信：既有 CNN 的多尺度特征图（对检测/分割友好），又保留注意力建模。Swin-L 在 ImageNet-22k 预训练后达约 87.3% top-1，一度是检测/分割的默认骨干。

归纳偏置之争的最终裁决（2021–2024 的共识）：偏置的价值与数据规模成反比——小数据下 CNN 的先验是免费午餐，大数据下先验变成"天花板"（全局注意力能学到卷积学不到的长程关系与组合性）；而当 ConvNeXt（arXiv:2201.03545）把 CNN 全面现代化（大核 7×7、LN、倒瓶颈等）后与 Swin 几乎打平，说明具体的算子（卷积 vs 注意力）不是本质，"全局信息交换 + 良好的训练配方"才是。对多模态的实际影响：ViT 胜出的直接原因是"同一个 Transformer 处理两种模态"，连接器与融合的设计因此简单得多——这就是第 9 章"模态共享骨架"的架构起点。

7.视觉表示学习：从监督到自监督

"ImageNet 预训练 → 下游微调"是深度视觉的黄金范式，但它有两个隐忧：标注昂贵（ImageNet 1400 万标注是几年人力），且监督信号（1000 个类别）只是图像信息的一小部分。2018–2022 年的自监督革命给出三条不依赖人工标签的路线：

对比学习：SimCLR（arXiv:2002.05709）与 MoCo（arXiv:1911.05722）让同一图像的两个增广视图在特征空间靠近、不同图像远离（InfoNCE，完整推导在第 12 章）；MoCo 用动量编码器维护负样本队列，SimCLR 靠超大 batch。线性探测精度一路逼近监督预训练。掩码建模：BEiT（arXiv:2106.08254）先做了离散 token 版；MAE（He et al., CVPR 2022，arXiv:2111.06377）给出最简洁的形态——随机遮住 75% 的 patch，编码器只处理剩下的 25%，一个轻量解码器从可见 token + 掩码占位重建像素。非对称设计（重编码器/轻解码器）+ 高掩码率让预训练快 3 倍以上，MAE ViT-H 微调后 87.8% ImageNet top-1。图文对比：CLIP（arXiv:2103.00020）用 4 亿自然图文对做对比学习，直接把"监督信号"换成了网络上的 alt-text——这条路线因为天然衔接语言而成为多模态时代的主干，第 12 章整章精读。

8.多模态视角：你的视觉塔从哪来

把本章与第 2、3 章拼起来，2026 年一个典型 VLM 视觉侧的"家谱"就清楚了：输入图像 → patch 切分（ViT 式，第 2 章）→ ViT 变体编码器（第 3 章的块 + 本章的层级/窗口/预训练选择）→ 连接器压缩（第 15 章）→ LLM。选哪个编码器，取决于三个本章铺垫过的问题：预训练信号（CLIP 式图文对比天然对齐语言，是 LLaVA/Qwen-VL 系的默认；MAE/DINOv2 式自监督空间细节强，常作第二编码器）、分辨率策略（固定 336 vs 动态 tile，第 22 章）、归纳偏置（纯 ViT 全局注意力 vs Swin 层级窗口）。CNN 并未绝迹：ConvNeXt 在部分数据混合实验中仍是有力基线，OCR/文档方向的检测头、SAM 的 mask 解码器周边也常用卷积组件。

📄 论文精读：Deep Residual Learning（He et al., CVPR 2016 最佳论文，arXiv:1512.03385）

问题：网络加深出现"退化"——更深模型的训练误差反而更高，说明不是过拟合而是优化困难；理论上 56 层网络至少应该能学到 20 层网络的解（多出的层学恒等即可），但普通结构学不动。方法：残差学习 $\mathbf{y} = \mathcal{F}(\mathbf{x}) + \mathbf{x}$，配合 BN 与恒等捷径；在 ImageNet 上训出 152 层模型，CIFAR-10 上甚至训过 1202 层（训练误差仍低，测试端过拟合）。关键结果：ILSVRC-2015 分类 3.57%（ensemble）、检测/定位冠军；COCO 检测相对提升约 28%（Faster R-CNN 换用 ResNet-101 主干）。为什么重要：残差连接是"让百层网络可训"的钥匙，今天从 LLM 到扩散 UNet 的每一个大型架构都是它的直接后代；第 3 章 Transformer 的残差流、第 24 章 UNet 的 skip connection（结构上是残差的表亲）都应放在这个谱系里理解。重读建议：第 3 节的"退化实验图"（20 vs 56 层）与第 4 节 "Deeper Bottleneck" 的 1×1 瓶颈设计（GoogLeNet 的 1×1 思想 + 残差）最值得精读。

🍳 实战配方：视觉侧选型速查

分类/检索原型：torchvision ResNet-50 或 timm ViT-B/16（IN-21k 预训练），224 分辨率起步。VLM 视觉塔：优先 CLIP/SigLIP 预训练的 ViT（openai/clip-vit-large-patch14-336、google/siglip-so400m-patch14-384 等），分辨率与 LLM 预算匹配；密集任务（OCR/文档）再叠 MAE/DINOv2 或动态 tile（第 14、22 章）。分割/grounding 数据：SAM 自动标注 + 人工抽检。训练：AdamW + cosine + warmup 3%（第 1 章）；视觉塔学习率设为 LLM 的 1/10；增强从简（Resize+CenterCrop 做评测，RandomResizedCrop+Flip 做训练）。评测：分类看 top-1/校准（ECE）；检测/分割看 mAP/IoU；密集预测对比线性探测——这些数字在 VLM 语境下分别对应第 40 章的各类基准。

⚠️ 陷阱清单：从 CNN 迁移到 VLM 语境的五个坑

（1）分辨率失配：视觉塔训练在 224/336，你喂 1024——ViT 会插值位置编码（第 3 章），patch 数暴涨且特征质量下降；高分辨率必须走 tile/AnyRes 方案（第 22 章）。（2）BN 与微调 batch：batch<16 时 BN 统计噪声大，冻结 BN 或换 GN/LN。（3）归一化统计错位：用 ImageNet mean/std 处理非自然图像（医学/遥感）往往不如 0.5/0.5/0.5，CLIP 系有自己的统计，要用对应 processor。（4）patch 数 = 分辨率²/14²：别用"图像大小"估显存，用 token 数（672×672 = 2304 token 而不是"一张图"），对接第 4 章的平方账。（5）增强破坏文本对齐：VLM 微调中视觉塔若参与训练，CutMix/Mixup 会把"图文配对"拆散，SFT 阶段慎用。

✏️ 自测（先独立作答，再看答案要点）

1. 推导：写出残差块的梯度公式，并说明"1 +"这一项为什么打断梯度消失。
答案要点：$\mathbf{x}_L = \mathbf{x}_l + \sum_{i=l}^{L-1}\mathcal{F}_i$，故 $\frac{\partial\mathcal{E}}{\partial\mathbf{x}_l} = \frac{\partial\mathcal{E}}{\partial\mathbf{x}_L}\big(1 + \frac{\partial}{\partial\mathbf{x}_l}\sum\mathcal{F}_i\big)$。普通网是纯连乘（每项<1 即指数消失）；残差加法里恒有系数为 1 的直通项，深层梯度可无损传回浅层。

2. 三个 3×3 卷积（stride 1）与一个 7×7 卷积感受野相同，为什么 VGG 选前者？
答案要点：参数 $3\times3^2C^2=27C^2$ vs $49C^2$；且非线性激活多 2 次，同感受野下表达力更强、更省参数。感受野公式 $RF_l = RF_{l-1}+(k_l-1)\prod s_i$ 验证 $1+2+2+2=7$。

3. BatchNorm 训练与推理行为有何不同？为什么 Transformer 换成 LayerNorm？
答案要点：训练用 batch 统计量并维护 running mean/var，推理用固定 running 统计（model.eval() 切换）。Transformer 用 LN 因为：序列长度可变、batch 内统计不稳定、有训练/推理差异、且 LN 对每个 token 的特征维归一化与 batch 无关，天然适配自注意力的逐位置计算。

4. 用"数据规模"解释 CNN→ViT 的范式转移，并给出论文证据。
答案要点：归纳偏置的价值随数据规模递减：ViT 论文 Figure 4 显示小数据下 ResNet 更好，预训练达 JFT-300M 级后 ViT 反超且所需计算更少（ViT-H/14 88.55%）。先验在小数据下是"免费午餐"，在大数据下限制上限；CLIP 的 4 亿图文对进一步证明规模解锁 Transformer 视觉。

5. Faster R-CNN 与 YOLO 的本质区别？RoIAlign 修复了什么？
答案要点：Faster R-CNN 两阶段（RPN 学习候选框 + RoI 精修，精度高、约 5 FPS）；YOLO 单阶段（网格直接回归框+类别，45–155 FPS、精度略低）。RoIAlign 用双线性插值取代 RoIPool 的取整量化，消除框与特征错位，对像素级掩码任务（Mask R-CNN）尤为关键。

6. MAE 的非对称设计与 75% 掩码率各解决什么问题？
答案要点：编码器只处理 25% 可见 patch → 预训练计算省约 3–4 倍；掩码 token 只进轻量解码器。75% 高掩码让"局部插值"式偷懒失效，迫使模型学习全局语义，才得到可迁移的表示（MAE ViT-H 87.8% top-1）。

7. 为什么 2023 年后的 VLM 视觉塔几乎都是"CLIP 式预训练的 ViT"，而不是 ImageNet 监督 ViT 或 ResNet？
答案要点：图文对比预训练的特征天然与语言对齐（零样本分类、检索、指令描述的起点好），数据规模（4 亿级图文对）让 ViT 充分发挥；ImageNet 1000 类监督的特征语义过窄，ResNet 缺全局注意力且与 LLM 的 token 化接口不匹配。分辨率与动态 tile（Qwen2-VL/InternVL）进一步建立在 ViT 的任意 patch 数灵活性上。
