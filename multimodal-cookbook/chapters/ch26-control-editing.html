💡 本章导读

SD 生成的图"好看但不受控"——想让它按指定姿态站、按指定线稿画、把白天改成黄昏，prompt 做不到。本章讲透"控制"的两大家族：结构控制（ControlNet/T2I-Adapter——把边缘、姿态、深度等空间条件注入 UNet）与语义控制（IP-Adapter——把参考图像变成提示词）；再加编辑三范式（SDEdit 的重噪声、P2P 的注意力操控、InstructPix2Pix 的指令编辑）。核心数学是那个已被验证为"万能钥匙"的模式：零初始化残差注入——第 13 章的门控、第 25 章预告的 ControlNet、第 36 章的 LoRA，都是它的化身。

1.控制的谱系：从 prompt 到像素

把"控制生成"按信号粒度排成一条谱：①语义级——文本 prompt（说了什么）；②风格级——参考图像的分布特征（画得像不像某种风格）；③结构级——边缘/深度/姿态/线稿（画在哪个位置）；④像素级——mask 与原始像素（inpaint 保留哪些区域）；⑤身份级——特定人脸/主体（画成"谁"）。不同粒度需要不同的注入机制——本章的地图就是把每种粒度映射到对应的架构方案。

2.ControlNet：zero-convolution 的完整数学

ControlNet（Zhang et al., arXiv:2302.05543，ICCV 2023 最佳论文候选）的问题设定：给定空间条件 $c_f$（Canny 边缘、OpenPose 骨架、深度图、分割图、涂鸦……），让预训练扩散模型"按图施工"，且不破坏原有能力（prompt 语义、画质、多样性）。

📐 理论推导：zero-convolution 为什么能"两全其美"

结构：把冻结 UNet 的 Down 段 + Mid 段复制一份为"可训练副本"，条件 $c_f$ 经一个小网络编码后与 $z_t$ 拼接进入副本；副本的 15 个输出（12 个 Down 残差 + 3 个 Mid）各自经一个 zero convolution（权重与偏置初始化为 0 的 1×1 卷积）加回原 UNet 的对应跳跃连接：

$$y_c = \mathcal{F}(x;\ \Theta_{\mathrm{frozen}}) + \sum_{i=1}^{15} Z_i\big(\mathcal{F}_i(x;\ \Theta_{\mathrm{frozen1}},\ \Theta_{\mathrm{ctrl}};\ c_f)\big),\qquad Z_i \equiv \mathbf{0} \ \text{at init}$$

三个设计决策的逐条论证：

①为什么复制而不是微调原模型？——微调会破坏预训练能力（灾难性遗忘）；副本保证"原模型分毫不动"，控制失效时输出=原模型输出（安全回退）。

②为什么零初始化？——训练开始时 $Z_i\equiv 0$，控制分支的输出被完全关闭，网络等效于原 UNet。设损失为 $\mathcal L$，对副本权重 $\Theta_{\mathrm{ctrl}}$ 的梯度：第一训练步 $\frac{\partial \mathcal L}{\partial \Theta_{\mathrm{ctrl}}} = \frac{\partial\mathcal L}{\partial y_c}\cdot Z_i'\cdot(\cdots)$ 项中 $Z_i$ 的权重梯度 $\frac{\partial \mathcal L}{\partial W_{Z_i}}$ = (上游梯度)·(副本输出) ≠ 0——$Z_i$ 自己会先学起来，然后逐渐"放行"控制信号；而副本深层权重的梯度（要穿过 $Z_i=0$）初始为 0，避免了随机初始化的大噪声冲击预训练激活。这与第 13 章 $\tanh(\alpha_0{=}0)$ 门控的梯度动力学完全同构："新增路径从零开始"是向预训练模型安全插入新能力的一般定理。

③为什么控制信号加在"每个分辨率级"而非一次注入？——空间约束是全尺度的（边缘既有大轮廓又有细节），逐级注入让每个分辨率的去噪都"看见"对应粒度的控制信号；消融显示只在单级注入可控性显著下降。

训练目标：标准扩散损失（预测 $\epsilon$），数据是"图像-条件- caption"三元组——条件用现成检测器（Canny/OpenPose/MiDaS）从图像自动提取，caption 用 BLIP 合成——大规模自动标注管线是 ControlNet 可行的另一半（呼应第 34 章数据工程）。训练用 50% 文本 dropout（保留无条件分支能力）。

📄 论文精读：ControlNet（Zhang L, Rao A, Agrawala M, ICCV 2023, arXiv:2302.05543）

问题：T2I 扩散模型"不受控"——prompt 无法表达空间结构；如何在不破坏预训练能力的前提下注入空间条件？方法：冻结 UNet Down+Mid 的可训练副本 + 15 个零初始化卷积把控制残差加回跳跃连接；训练数据用检测器自动构造（Canny/Pose/Depth/HED/涂鸦/分割 × BLIP caption），3M 级三元组。关键结果：单卡 30GB 可训练（当时），控制精度与画风保持双达标；Canny/姿态任务的可用性直接催生 ControlNet 生态（上百个条件类型变体）。为什么重要：它把"可控生成"从论文概念变成大众工具（A1111 插件下载量千万级）；其"零初始化残差注入 + 副本训练"模式是向预训练大模型加能力的通用蓝图。批判性阅读：推理开销约 +50%（副本前向），后续 T2I-Adapter/Control-LoRA 是效率补偿；条件泄露问题（复刻控制图伪影）论文未充分讨论——生产使用必须做条件预处理。

🕰 历史一刻：2023 年 2 月，"ControlNet 时刻"

ControlNet 论文与代码在两周内引爆社区——因为它是第一个"消费级显卡可训练"的扩散微调范式：副本训练把所需算力从"预训练级"降到"微调级"，个人创作者第一次能给 SD 添加"新能力"而不只是"新风格"。配套的自动条件构造管线（现成检测器+BLIP caption）示范了"领域数据不必人工标注"的数据工程范式。此后三个月，社区发布了 40+ 条件类型的 ControlNet 变体——这种"一个范式、百种实例"的裂变速度，是开源扩散生态成熟的标志，也为第 45 章 ComfyUI 的节点化工作流时代提供了积木。

2A.ControlNet 训练的完整配方与代价核算

为特定领域训练专属 ControlNet（如医学影像的器官边缘控制、工业质检的缺陷位置控制）是常见需求。完整配方：数据——目标域图像 + 检测器提取条件（领域专用条件器可能需要先训，如医学分割模型）+ caption（BLIP/VLM 自动生成，领域术语要后处理校正）；规模 5 万–50 万对即可起步（通用能力由冻结主干提供，副本只学"条件→残差"映射，数据需求远小于预训练）。训练超参：lr 1e-5（AdamW）、batch 48–128（越大越稳）、50% caption dropout、控制图随机 dropout 5%、约 3–8 万步收敛（副本只有 350M）。代价核算：单卡 A100 约 3–7 天（30GB 显存配置），数据准备（条件提取+caption）约 1–2 天——比全参微调便宜一个量级，比 LoRA 贵但换来的是"结构控制"这个 LoRA 做不到的能力。

验证协议（训练 ControlNet 专有）：①控制服从度——生成图与条件图的边缘 IoU/骨架匹配率（专用指标：mAPose/Canny-F1）；②风格保持——同 prompt 不加控制的输出与加控制的输出在"非控制区域"应一致（不破坏画质）；③条件敏感性曲线——controlnet_conditioning_scale 从 0 到 2 扫描，理想曲线是"0 时与原模型一致、0.5–1.2 之间平滑增强、>1.5 伪影"——曲线陡峭说明训练过拟合。

💡 技巧：ControlNet 的"零成本迁移"实验

一个有趣的免费实验：把 A 领域训练的 ControlNet 用到 B 领域（如人脸姿态 ControlNet 用于动物）。结果通常是"部分有效"——因为副本学的是"条件图→UNet 残差语言"的翻译，而 UNet 主干懂"动物长什么样"；姿态骨架的语义在人与动物间部分共享。控制的"语言"（残差空间）与"内容"（主干知识）是分离的——这个实验直观展示副本-主干解耦设计的价值：控制能力可迁移、内容知识不丢失。同理可解释为什么多 ControlNet 能叠加（多路"翻译"在残差空间线性组合）。

3.T2I-Adapter 与轻量替代

T2I-Adapter（Mou et al., arXiv:2308.06721）是 ControlNet 的"轻量版哲学"：不复制 UNet，只训一个小适配器（约 77M 参数 vs ControlNet 副本 ~350M）。条件 $c_f$ 经几层卷积提取多尺度特征，直接加（或拼接）到 UNet 各级的输出上：

$$\phi_t \leftarrow \phi_t + A_t(c_f),\qquad A_t\ \text{为第}\ t\ \text{级适配器（零初始化输出层）}$$

取舍：参数少、训练快、推理开销小（无副本前向），可控性弱于 ControlNet（没有"完整的去噪副本来理解条件"）——对粗粒度控制（调色、简单构图）够用，精细姿态复刻仍需 ControlNet。同一思想族还有 Control LoRA（用 LoRA 形式注入控制分支）与后来的 ControlNet++（加一致性奖励循环）。选型口诀：算力充足要精度 → ControlNet；要轻快可插拔 → T2I-Adapter/Control-LoRA。另外注意生态现实：SD 生态中 ControlNet 的模型覆盖（各条件类型 × 各底座版本）远大于替代品——生态位有时比架构更决定选择。

4.IP-Adapter：图像作为提示词

IP-Adapter（Image Prompt Adapter，Ye et al., 2023，腾讯）解决另一个维度：用一张参考图控制生成（风格、内容、色调），而不动文本通道。机制：解耦交叉注意力（decoupled cross-attention）——在 UNet 的每个 attn2 旁边并联一个新的交叉注意力层，其 K/V 来自参考图的图像编码（CLIP image encoder 输出经投影 + 4 个可学习 token 扩展），输出与文本注意力输出相加：

$$Z = Z_{\mathrm{text}} + \lambda\, \mathrm{XAttn}(Q,\ K_{\mathrm{img}},\ V_{\mathrm{img}}),\qquad \lambda\ \text{可调（图像影响力）}$$

"解耦"的含义：文本走原通道、图像走新通道，两者不互相污染——可以"画一只猫（文本）但要像参考图的光影（图像）"。IP-Adapter 只有 ~22M 参数（只训新注意力与投影），可插拔、可与 ControlNet 叠加。它的后续变体：IP-Adapter FaceID（用 InsightFace 的人脸 embedding 替代 CLIP 图像特征，专攻人脸一致性，配合 InstantID 构成"零训练换脸"主流）；IP-Adapter Plus（16 token、逐层更强）。图像即提示词（image prompt）的思想在 2024–2026 成为标配——SD3/Flux 的 reference 支持、各家"垫图"功能都是它的产品化。

💡 技巧：风格控制的强度天平

IP-Adapter 使用中最常见的问题是"图像权重过高导致文本失效"（output = 参考图的复读）。调参经验：λ 从 0.4 起步（0.6+ 会明显压制文本）；风格控制用"参考图 + 简短文本"；主体控制必须叠加 mask 或 ControlNet 锚位置。另一个技巧：参考图本身也过一遍 ControlNet（用其边缘做条件）可以"锁定构图"的同时换内容——两把锁一起拧，是电商换背景、头像换风格的标准组合。

5.图像编辑三大范式：SDEdit、P2P、InstructPix2Pix

5.1 SDEdit：把图"弄脏"再让它变干净

SDEdit（Meng et al., arXiv:2108.01073，ICLR 2022）是最早的"零训练编辑"：把输入图加噪到中间时刻 $t_0$（strength 参数），再从 $x_{t_0}$ 走正常去噪（可以带新 prompt）。原理：加噪到 $t_0$ 丢掉"$(1-t_0)$ 比例的高频细节"，保留低频结构；去噪过程在新条件引导下"重新想象"细节。strength 的语义（第 25 章已实现代码）：低=微调（保结构）、高=重绘（换结构）。局限：结构保留与编辑幅度天然互斥——想"只改颜色"时细节也常被重绘。这个缺陷催生了更精细的编辑方法。

5.2 Prompt-to-Prompt：在注意力层做手术

P2P（Hertz et al., arXiv:2208.01626，ICLR 2023）的洞察：交叉注意力的权重图就是"词→区域"的绑定（第 25 章 attn2 的推论）。编辑时保持结构=锁定"结构词"的注意力图、只替换"内容词"的注意力：

$$A_t \leftarrow \begin{cases} A_t^{\mathrm{src}} & \text{（共享词的注意力，保留布局）}\\ \mathrm{softmax}(\cdots)^{\mathrm{tgt}} & \text{（替换词的新注意力）}\end{cases}$$

用两段生成（源 prompt 正常生成记录注意力，目标 prompt 生成时按规则替换/注入源注意力）实现"把猫换成狗但布局不变"。变体 Plug-and-Play（PnP，arXiv:2305.02215）直接注入源图的自注意力与交叉注意力值——无需同源 prompt，任意图都能编辑。P2P 系的价值在于揭示了注意力的"布局承载"作用——后续的区域控制（regional prompting、gligen 系）都是它的工程化。

5.3 InstructPix2Pix：学会"听人话改图"

InstructPix2Pix（Brooks et al., CVPR 2023）把编辑变成条件生成问题：模型输入（原图 + 编辑指令文本），输出编辑后图像。训练数据的生成是它最漂亮的贡献——合成数据三步走：①GPT-3 生成"指令-前后 caption"三元组文本；②用 T2I 模型分别生成前后图；③用微调的编辑模型（ Prompt-to-Prompt 微调版）过滤一致性差的样本。最终 ~300k 合成对训出 7B 级模型（两个 UNet 分支：原图作为额外条件、指令作为文本条件）。"用模型生成数据训练更强的模型"的自举范式（呼应第 34 章数据飞轮）在此首次大规模验证，后续 DALL-E 3 的合成 caption、第 16 章的指令数据都是同族。

💡 技巧：编辑任务的"方法选择树"

拿到一个编辑需求，按序判断：①能否用 mask 圈出要改的区域？能 → inpaint（最可控）。②改动是"换词"级别（颜色/物体）吗？是 → P2P/PnP 或 InstructPix2Pix。③改动是"整体风格/光影"吗？是 → SDEdit 低强度或 IP-Adapter 风格参考。④需要"按指令精确改"且批量？→ 微调自己的 InstructPix2Pix（合成数据管线）。多数"编辑效果差"的抱怨，根源是方法选错而非模型不行。

4A.InstantID 与身份保持：从"像"到"是"

身份保持（identity preservation）是风格控制之外更苛刻的要求——"生成的每张图都是同一个人"。技术栈的演进值得梳理：①LoRA/DreamBooth 路线——每人 5–20 张图训练，像度最高但"每人一训"不可规模化；②embedding 注入路线——PhotoMaker（arXiv:2312.04461）把多张参考照的人脸特征编码为"身份 token"放入文本序列，一次推理换任何人；③即插即用路线——InstantID（2024）：InsightFace 提取身份 embedding（ArcFace 空间，天然解耦身份与姿态/表情）+ 一个轻量 identity-aware ControlNet 锁五官结构，单张参考照、零训练、秒级；IP-Adapter FaceID 同族（用人脸 embedding 替代 CLIP 图像特征）。权衡：免训练方法的一致性"像度"约等于 5–10 张图的 LoRA（主观评测），但跨视角/跨年龄的稳定性仍不如专用训练；商用换脸必须叠加合规层（第 47 章的肖像权与 deepfake 法规）。

解剖 InstantID 的组合拳（它是"多机制协同"的教科书案例）：身份信息走两条路——语义路（ArcFace embedding 经投影进解耦注意力，管"长什么样"）+结构路（identity ControlNet 用参考照的人脸关键点/热图，管"五官在哪个位置"）。双路各自 zero-init 注入（又是那个元模式）。给实践者的启示：当单一注入机制无法同时满足"语义正确+空间正确"时，双路注入是标准解法——这个设计模式在可控生成的每个细分场景都会重现。

5A.编辑评测：怎么衡量"改得好"

编辑方法 lacking 统一基准是 2023–2025 的痛点，2024 年后逐渐收敛的评测框架：①InstructPix2Pix 评测协议——CLIP-I（编辑结果与目标描述的相似度）+ L1/LPIP（与"不该变的区域"的保真）双指标；②Emu Edit 协议（arXiv:2311.10089 系）——把编辑任务分为 local/global/add/remove/replace/color 六类分项评测，揭示"各方法擅长什么"（如 inpaint 强 local、IP2P 强 color/style）；③人类偏好——编辑质量最终靠盲评（保真-服从-画质三轴）。实践者的两个坑：一是只看"服从"不看"保真"（改了该改的也改了不该改的）；二是用低分辨率评测（512 下各方法差异不显著，1024 才拉开差距）。

💡 技巧：编辑管线的"后悔药"设计

生产编辑系统的实用架构：每步编辑保留"编辑谱系"（原图→每次操作记录：方法/参数/mask），支持回滚与分支重放（类似 Git）。实现要点：编辑操作元数据化（JSON 记录 SDEdit 的 strength、inpaint 的 mask 坐标、P2P 的替换词表），任意中间状态可重建。ComfyUI 的节点图天然具备此性质（工作流即谱系），这是它在专业编辑场景胜出的深层原因——可复现性不是工程洁癖，而是创作工作流的刚需。

6.组合控制与工程实践

真实需求几乎都是多控制叠加："这个姿态（OpenPose）+ 这个背景（深度图）+ 这个角色（IP-Adapter FaceID）+ 这个风格（LoRA）"。组合的理论与工程要点：①冲突仲裁——多个控制信号在注意力/残差上叠加，彼此可能矛盾（Pose 说手在左、边缘图说在右）；ComfyUI 的权重滑条就是人工仲裁器，经验是"硬结构（边缘/深度）权重 > 软控制（IP/风格）"，CFG 过高会放大所有控制（包括坏控制）。②多 ControlNet 叠加——各 ControlNet 的 15 路残差独立求和加回，参数互相独立可训；工程上注意显存（每个 ControlNet ~1.4GB FP16）。③分辨率与条件对齐——条件图必须与生成分辨率严格对齐（含 crop 元数据），错位是"控制失效"的第一大原因。

⚠️ 陷阱：ControlNet 的三大失效模式

①"控制图泄露"——输出图像把控制图的伪影直接画出来（如 Canny 的毛刺、深度图的量化阶梯）：条件图质量差导致，预处理（边缘去噪、深度图平滑）先于调参。②"控制失效"——CFG 过低（<5）或 ControlNet 权重过低：结构约束需要足够的 CFG 放大，经验 ControlNet weight 0.8–1.2、CFG 7 起。③"画蛇添足"——控制图与 prompt 矛盾（边缘是站姿、prompt 写跑步）：扩散会取折中产出畸形——prompt 与控制图的一致性检查应成为管线的固定步骤（可用 VLM 自动审查，第 43 章）。

把本章所有方法放进第 24 章"条件注入地图"（注意力/拼接/调制/分支），可以提炼一张选型矩阵——这也是读任何新控制论文时的解剖框架：①它注入在哪？（attn2 旁=语义级、Down 残差=结构级、输入拼接=像素级）；②它训练什么？（全新层=轻、副本=重、LoRA=最轻）；③它需要什么数据？（检测器自动=免费、人工=贵、模型自举=快）；④推理开销？（副本 +50%、Adapter +5%、IP-Adapter +10%）。

6B.一致性生成专题：跨图与跨帧的角色稳定

"同一个角色在 10 张图里长一样"是连环画/漫画/广告的刚需，也是生成的老大难。技术坐标：①训练法——每角色一个 LoRA/DreamBooth（第 28 章），一致性最强但每角色要训练数据；②免训练法——IP-Adapter FaceID/InstantID（一张参考照注入身份）；③生成时法——固定 seed+固定 prompt 结构（弱）、先生成角色定妆照再用 IP-Adapter 垫图（社区标准工作流）；④注意力共享法——MasaCtrl/ConsiStory（arXiv:2402.03286 系）把参考图的 K/V 直接共享给新图生成（零训练跨图一致性的学术主流）。工程现实：连环画生产的主流管线 = "定妆照 + IP-Adapter + ControlNet（构图）+ 人工修图"，一致性是"工程近似"而非"完全解决"——角色一致性仍是 2026 年生成领域的活跃问题。

🍳 实战配方：从需求到管线的完整映射表

🕰 历史视角：从 GAN 的可控生成到扩散的控制生态

"可控图像合成"不是扩散时代的新问题——GAN 时代有完整的控制尝试：StyleGAN 的风格向量编辑、GAN inversion（把真实图反演到 GAN 潜空间再编辑，arXiv:2012.09841 系综述）、条件 GAN（pix2pix/SPADE 的空间条件）。扩散时代的三点超越：①零样本泛化——GAN inversion 逐图优化数分钟，SD+ControlNet 一次前向；②条件类型自由——SPADE 每种条件一个模型，ControlNet 一个范式任意条件；③开放词汇——文本条件的语义空间天然开放（GAN 的类别封闭）。回看历史，ControlNet 的成功=扩散的生成质量+GAN 时代的空间控制思想+零初始化的训练安全性——每个时代的问题会被下一个时代的基建重新解决一遍，这是读技术史的复利。

再补一段"控制强度"的定量直觉（调参时的心理模型）：ControlNet 的 conditioning_scale 相当于把控制残差乘以标量 $s$。$s{=}0$ 即关闭、$s{=}1$ 即"按训练分布使用"、$s{>}1$ 属于分布外推——与 CFG 的 γ 完全同构（都是"条件方向的外推系数"）。经验区间与对应的"控制语气"：$s{<}0.5$ 建议式（控制图是参考）、$0.8 ext{–}1.2$ 要求式（按图施工）、$s{>}1.5$ 强制式（结构锁死，画面易僵化）。与 CFG 的联动：两者都在放大"条件方向的梯度"，总外推强度 ≈ 乘性叠加——这就是"高 CFG + 高控制权重 = 崩图"的数学解释；推荐起点：CFG 7 + scale 1.0，两者各调 ±20% 观察。

分辨率与控制精度：条件图在潜空间被 8 倍下采样——512 生成时 8×8 分辨率层的每个 token 对应原图 64×64 像素区域，小于 8px 的控制细节在最低分辨率层不可见。含义：精细控制（小字、细线稿）依赖高分辨率生成（1024+）或 ControlNet 的 64px tile 化使用；"控制不精确"的抱怨，一半是"控制细节小于潜空间分辨率"的物理极限。

✏️ 自测

1. 写出 ControlNet 的输出组合式；zero-conv 为什么能同时保证"安全性"与"可训练性"？
答案要点：$y_c=\mathcal F(x)+\sum Z_i(\cdot)$，$Z_i\equiv0$ 起步；安全性=起步时输出=原模型；可训练性=$Z_i$ 的梯度非零先学起来、副本深层穿过零门后逐步获得梯度——噪声不冲击预训练激活。

2. ControlNet 与 T2I-Adapter 的取舍？
答案要点：CN=完整副本（~350M）控制强、开销大；Adapter=轻量加法（~77M）快但粗；生态覆盖也是决定因素。

3. IP-Adapter 的"解耦"指什么？为什么能"文本管内容、图像管风格"？
答案要点：文本走原 attn2、图像走并联新注意力层再相加——两通道独立，λ 可调影响力，互不污染。

4. SDEdit 的 strength 语义？为什么"只改颜色"常连带重绘细节？
答案要点：strength=入场噪声时刻；加噪丢高频保低频，细节属高频故被重新想象——结构与幅度互斥是 SDEdit 的固有缺陷。

5. P2P 的机制洞察是什么？PnP 的改进？
答案要点：交叉注意力权重图=词→区域绑定，替换/注入注意力实现"布局不变换内容"；PnP 直接注入源图注意力值，无需 prompt 对齐。

6. InstructPix2Pix 的数据自举三步？这个范式的现代后裔？
答案要点：GPT-3 生成指令文本 → T2I 生成前后图 → 编辑模型过滤；后裔：DALL-E 3 合成 caption、多模态指令数据（第 16 章）——"模型造数据训更强模型"。

7. 多 ControlNet 叠加时"控制图与 prompt 矛盾"会怎样？如何预防？
答案要点：扩散取折中产生畸形；预防：管线中用 VLM 自动审查 prompt-条件一致性，人工审核关键条件图。

8. conditioning_scale 与 CFG 的数学同构性是什么？为什么"两者都高"会崩图？
答案要点：都是条件方向的外推系数（乘性叠加总外推强度）；超出训练分布导致过饱和与伪影——总强度要预算控制。

9. 为什么"小于 8px 的控制细节"在 512 生成中不可见？
答案要点：条件图随潜空间 8 倍下采样，8×8 层每 token 对应 64×64 像素；精细控制需高分辨率或 tile 化——这是物理极限而非调参问题。
