💡 本章导读

2023–2026 是文生图的"三代跃迁"：SD1.5 时代的"咒语学"被 DALL-E 3 的合成 caption 终结；扩散 U-Net 被 DiT/MMDiT 取代；ε-预测被 rectified flow 取代；CFG 被引导蒸馏内化。本章沿着这条主线，解剖三个里程碑——DALL-E 3（数据侧革命）、SD3（目标函数与架构革命）、Flux（工程化集大成）——并覆盖自回归复兴（LlamaGen/VAR）与闭源新形态（GPT-4o 原生生图）。读完你将获得一张"2026 年选 T2I 模型"的完整地图。

2.DALL-E 3 与"重标注革命"

DALL-E 3（OpenAI，2023 年 10 月；技术报告 arXiv:2310.16825）在架构上并不激进（仍是扩散+CLIP 文本塔），它的革命在数据侧：先训一个图像 captioner（能生成"密集、详细、描述性"的 caption——不只说"有什么"，还说风格、构图、光影、文字内容），用它给训练集全部重新标注，再训 T2I。为什么这是革命：原网络 alt-text 的 caption 短、噪、与图像弱相关——模型学到的是"prompt 与图像的统计松耦合"，于是用户必须写"咒语"（触发词+权重语法）；重标注后 caption 与图像"语义强耦合"，自然语言直接可用——prompt 工程死了，"说话就行"活了。

📐 理论视角：为什么 caption 质量决定 prompt 遵循上限

条件生成的信息论视角：模型学的是 $p(x\mid c)$，其中训练时的条件 $c$ 是数据集 caption。若 $c$ 与图像内容 $x$ 的互信息低（caption 缺细节），模型只能学到"边缘化的 $p(x)$"——prompt 中再多细节也传不进去（训练时根本没见过"细节在 caption 里被表达"的样本）。推论：推理时的 prompt 分布应与训练 caption 分布匹配——这就是"咒语学"的本质（用户手工把自然语言调制成训练 caption 的风格），也是重标注后"自然语言即 prompt"的原因（合成 caption 本身就是自然语言）。这个"caption-图像互信息决定条件生成上限"的定律，是生成数据工程的第一性原理——第 16 章 VLM 指令数据、第 34 章数据工程都在它的统治下。

重标注的生态影响立竿见影：SDXL 之后的开源模型全部跟进合成 caption（PixArt-α、SD3、Flux 的训练管线皆然）；"用 VLM 给图像打标"成为数据工程的标配工位；甚至反过来影响了多模态 LLM 的 SFT 数据（第 16 章 ShareGPT4V 同族思想）。DALL-E 3 证明了：数据侧的改进可以不打架构仗就实现能力跃迁——这个教训对资源有限的团队尤其重要。

🍳 实战配方：为你的 T2I 微调数据做一次重标注

场景：你有 5 万张业务图像（商品/室内/动漫），要微调 Flux/SDXL 但原始标注只有文件名或短标签。步骤：①选 captioner——VLM（Qwen2.5-VL-7B / InternVL）优于 BLIP 系（描述更长、属性更准）；②写caption 指令模板：要求按"主体—动作/状态—场景—风格—构图/光影—文字内容"顺序输出 1–3 句，禁止评价性词汇（"beautiful"类），保留客观特征；③三档长度混合：对每张图生成短（1 句）/长（3–5 句）两版，训练按 3:7 混合——保短语可用性；④幻觉过滤：用 CLIPScore 对 caption-图像打分，低于阈值的丢回重写；⑤去重：caption 语义去重（嵌入聚类）防止过拟合到模板句式。成本：7B VLM 单卡一天可标 5 万张（vLLM 批推理）——重标注已经不是大厂专利。

📄 论文精读：DALL-E 3 技术报告（arXiv:2310.16825）

写作形态：这不是常规论文而是"数据工程白皮书"——架构几乎不提，全部篇幅在讲 captioner 与数据。三个可复用结论：①caption 描述性训练——captioner 用"短 alt-text 与长合成描述混合"训练，避免只会写长句、丢掉原图分布的短描述能力（否则 T2I 训练分布再次偏移）；②描述子类型谱系——合成 caption 按详细程度分档（短/中/长），T2I 训练时按比例混合，使模型在"短语 prompt"与"长文 prompt"下都不崩；③先验重置——重标注后模型不再需要负面词与权重语法，官方 prompt 指南同步改写为"像说话一样写"。可复制性：开源社区后来用 LLaVA/Qwen-VL 系复现了整条管线（如 SD3 训练数据中的 caption 混合策略），成本从"大厂专属"降到了"单人可跑"。遗留问题：captioner 的幻觉会写进数据集——描述了不存在的东西，T2I 就学出"凭空添加"的先验，这是生成式数据工程的固有税。

3.自回归路线：Parti、LlamaGen 与 VAR

自回归 T2I 在 2022–2024 三次尝试撼动扩散：Parti（Google，arXiv:2206.10789，2022）——ViT-VQGAN 离散化 + 20B 自回归 Transformer，证明"序列建模可以规模化到语言模型的水平"，质量强但 20B 推理昂贵；LlamaGen（arXiv:2406.06525，2024）——"LLaMA 式架构直接做 T2I"，775M–3B 规模 + 改进的 VQ tokenizer，开源路线证明 AR 可与 SDXL 掰手腕；VAR（Visual AutoRegressive，arXiv:2404.02905，NeurIPS 2024 杰出论文）——把"逐 token 左到右"改成"由粗到细的多尺度 VQ 逐级生成"（每个尺度一次并行预测，像"从马赛克到高清"），复杂度从 $O(n^2)$ 降到 $O(n\log n)$ 级，且首次在 AR 路线复现了 scaling law（零样本泛化随规模幂律提升）。

AR 路线的本质优势与困境：优势——与 LLM 完全同构（可统一进一个模型，第 19–20 章的原生路线）、似然精确可算、scaling law 清晰；困境——VQ tokenizer 的重建上限（第 19 章"按冗余付费"）、逐 token 生成的序列长度（1024 token/图起步）。VAR 的多尺度设计部分缓解了两者（每尺度 token 数少+粗细粒度分离），被后续统一模型广泛借用。2026 年的判断：AR 与扩散的路线之争已转化为"统一模型内部用什么生成头"的子问题（Janus 的解耦、Transfusion 的混合、Emu3 的纯 AR——第 20 章）。

第三条变体：MAR（Masked Autoregressive，arXiv:2406.06525 同篇提出）——干脆丢掉 VQ：用扩散损失回归连续 token（每个 token 输出均值+方差，按 diffusion loss 采样），配合随机掩码顺序（每次预测任意位置的子集，像 MaskGIT 的因果化）。MAR 证明"AR 的因果建模"与"扩散的连续回归"可以杂交——精度上 MAR-L 超过同规模 DiT，且不需要量化器。三条变体（Parti 的纯离散 AR、VAR 的多尺度、MAR 的连续掩码）合起来构成了"AR 挑战者联盟"。

📄 论文精读：VAR（NeurIPS 2024 杰出论文，arXiv:2404.02905）

动机：图像自回归长期落后于扩散——GPT 式"逐 token 光栅序"既慢（序列长）又怪（光栅序并非图像的自然层级）。核心设计：①训练一个多尺度 VQ tokenizer（1×1→16×16 共 $K$ 级，每级是一张"该分辨率下的残差量化图"）；②Transformer 生成时以尺度为单位——每级先缓存前一级信息，再块内全并行预测本级所有 token；③注意力用"尺度间因果、尺度内双向"的掩码。收益：生成质量超过 L-DiT 级扩散基线（FID 1.73@ImageNet 256），推理速度大幅领先；更关键的发现是零样本泛化的 scaling law 首次在 AR 视觉路线成立——这为"视觉也有 GPT 时刻"提供了证据。影响：VAR 的多尺度残差化思想被 2025 年后的多个统一/生成模型借用（多尺度残差是"光栅序"之后 AR 视觉最重要的序列设计）。局限：tokenizer 仍是 VQ（重建上限仍在）；文本条件设定在 ImageNet 类别，开放域 T2I 需接 LLM。

4.SD3：Rectified Flow 的完整推导

Stable Diffusion 3（Esser et al., arXiv:2403.03206，2024 年 3 月）是 Stability 与 LDM 团队的"重构之作"，论文前半部分是一次系统的目标函数大比武：在相同架构与数据下比较 rectified flow、EDM 型扩散、DDPM 型——结论：rectified flow 在 60+ 配置对里全面占优（尤其高噪声区间）。

📐 理论推导：Rectified Flow 与 Flow Matching（呼应第 24 章预告）

构造：定义一条连接噪声与数据的概率路径——最简单的选择是直线插值：$x_t = (1-t)\,x_0^{\mathrm{noise}} + t\,x_1^{\mathrm{data}}$，$t\in[0,1]$（记号注意：SD3 论文取 $t{=}0$ 噪声、$t{=}1$ 数据）。沿这条路径的"速度"恒为 $v = x_1 - x_0$（与 $t$ 无关！）。训练目标：网络 $v_\theta(x_t, t)$ 回归这个速度：

$$L_{\mathrm{CFM}} = \mathbb{E}_{t,\,x_0\sim\mathcal N(0,I),\,x_1\sim p_{\mathrm{data}}}\big[\|v_\theta(x_t, t) - (x_1 - x_0)\|^2\big]$$

（CFM=Conditional Flow Matching，条件路径的流匹配——与 diffusion 的 $\|\epsilon-\epsilon_\theta\|^2$ 惊人地形式相似：都是"回归一个向量场"，区别在向量的定义。可以证明：扩散的 $\epsilon$ 预测等价于某种曲线路径下的 flow matching——rectified flow 选择了"最直的路径"。）

为什么"直"是好性质：生成 = 从 $t{=}0$ 积分 ODE $\frac{dx}{dt}=v_\theta(x,t)$ 到 $t{=}1$。路径越直，速度场越接近常数，ODE 的数值积分越容易——少步采样的理论根据。Rectified flow 的 "reflow" 操作（用训练好的模型生成新配对再重训）进一步拉直路径，理论上一轮 reflow 后单步生成成为可能。SD3 的实测：20 步内 FID 与 250 步扩散持平。

对数似然：ODE 视角下 instantaneous 变化由连续性方程约束，模型的对数似然有精确的迹公式（Hutchinson 估计）——flow 系模型保留"可算似然"的加分项（扩散的 ELBO 等价也成立）。

训练细节：时间采样分布很关键——SD3 用对数正态加权的 $t$ 采样（中间噪声区间多采，两端少采），消融显示这一项对质量的贡献不亚于换目标函数本身（EDM 的"调度最值得调"结论在 flow 框架下的重演）。

一个统一的视角：把 DDPM、EDM、rectified flow 都写成"概率路径+对应速度场"的形式，差异就只剩两个选择——路径形状（方差保持的高斯桥、ve/vp 插值、直线路径）与参数化（$\epsilon$ / $x_0$ / $v$）。SD3 论文的实验结论可以压缩成一句："路径越直 + 高噪声区间权重越高，训练越稳、少步采样越好"。这个视角还统一了直觉：扩散模型学的是把噪声"搬运"到数据的向量场，所有调度技巧都在改搬运路线。对工程师的启示是：换目标函数不是玄学，是几何——当你需要少步采样（视频生成、交互式编辑），优先选 flow；当你只有单步预算，选一致性/蒸馏路线。

5.MMDiT 与架构细节

SD3 的架构是 MMDiT（Multimodal Diffusion Transformer）：文本 token 与图像 patch token 不拼接共享一套权重，而是各自拥有独立的 QKV/O 投影，但在同一注意力中互为 K/V——"两套权重、一个注意力场"。与 SD1.5 的"图像查文本"（交叉注意力不对称）对比：MMDiT 让文本与图像对等对话（第 25 章 3A 节的"对称性"顶格实现），文字渲染与属性绑定（"红色的猫和蓝色的狗"）显著改善。其它细节：QK-Norm（第 19 章 Chameleon 的稳定性技术，防止注意力 logits 爆炸——大模型训练稳定性知识跨域迁移的案例）；双/三文本编码器——CLIP-L + CLIP-G + T5-XXL（前三层冻结）组合，T5 的长文本理解补足 CLIP 的 77 token 短板（复杂排版与长描述）；位置编码用 2D RoPE 变体。比例缩放：SD3 提供 800M/1.6B/2B/8B 四档——DiT 化后的 scaling curve 首次在开源 T2I 中清晰呈现。

💡 技巧：读懂"新一代 T2I 架构图"的模板

2024–2026 年的 T2I/视频模型架构图高度模板化，读图顺序：①找 token 流——文本/图像/时间（视频）各自的 token 化与位置编码；②找注意力拓扑——联合（MMDiT/Flux）还是分层（UNet 残余）？双流权重独立还是共享？③找条件注入——adaLN 调制（时间/全局）+ 联合注意力（语义）+ 附加通道（size/ref）；④找训练目标——flow/ε/v？时间采样分布？⑤找稳定性件——QK-norm、zero-init、norm 类型。五问答完，SD3/Flux/PixArt/HunyuanVideo 的架构差异基本就是"同一模板的参数选择"。

6.Flux：引导蒸馏与 12B 的新平衡

Flux.1（Black Forest Labs，2024 年 8 月，SD 原作者团队创立的公司）把 SD3 的技术栈推向工程化极致：12B 参数的 MMDiT 变体（双流+单流混合块）、16ch VAE、RoPE、引导蒸馏（guidance distillation）——把 CFG 的双分支外推蒸进权重（一个专用的"引导输入"标量替代推理时双前向），推理免 CFG 省一半算力。三档发布策略也成为范本：Flux Pro（API）、Flux Dev（非商用开放权重）、Flux Schnell（Apache 2.0，1–4 步蒸馏）——"能力/许可/速度"三轴的矩阵化产品。质量上 Flux 在文字渲染、人体结构、prompt 遵循上把开源 T2I 推到与 DALL-E 3/Gemini 同档；2024 末–2025 的 Flux 生态（LoRA/Control/工作流）复刻了 SD1.5 的社区繁荣。

🍳 实战配方：2026 年 T2I 选型决策树

第一问：需要开放权重吗？否 → 闭源 API（GPT-4o 图像/Gemini/Imagen——对话式生成与编辑一体化最强）。是 → 下一问。
第二问：算力预算？消费级 12–24GB → SD1.5/SDXL 生态（LoRA 海量）或 Flux Schnell；专业 24GB+ → Flux Dev/SD3.5 Large。
第三问：需要精细控制（ControlNet/IP-Adapter 生态）吗？强需求 → SDXL（生态最全）或 Flux（生态快速追平）；弱需求 → 任意新模型。
第四问：文字渲染/多主体是核心吗？是 → Flux/SD3.5/闭源旗舰。
第五问：批量生产成本？——全部上蒸馏（4 步）+ 引导内建，延迟优先 Turbo 系。一句话：2026 年的默认答案是"Flux Dev/Schnell 或 SD3.5"，生态迁移成本是主要摩擦项。

Flux 的蒸馏细节值得展开：guidance distillation 训练一个"学生"模型去拟合"CFG 外推后的教师输出"（学生输入一个引导标量 $\gamma$，输出 $\epsilon_\gamma = \epsilon_c + \gamma\cdot(\epsilon_c-\epsilon_u)$ 的目标），推理时单前向即可获得任意引导强度；步数蒸馏（Schnell 的 1–4 步）则叠加了对抗损失+分布匹配蒸馏（LADD 思路）。两段蒸馏的代价：学生的"可编辑性"略降（负面 prompt 消失、极端引导区间失真）——蒸馏是用灵活性换部署效率的典型交易，与第 39 章推理部署的量化交易同构。

💻 代码：用 Diffusers 跑 SD3 / Flux（含 CFG 与引导蒸馏对比）

from diffusers import StableDiffusion3Pipeline, FluxPipeline
import torch

# --- SD3.5：传统 CFG（双前向，guidance_scale 是推理期外推）---
pipe_sd3 = StableDiffusion3Pipeline.from_pretrained(
    "stabilityai/stable-diffusion-3.5-large", torch_dtype=torch.float16
).to("cuda")
img = pipe_sd3(
    prompt="A ceramic teacup on a windowsill, morning light, film photo",
    negative_prompt="blurry, watermark",
    num_inference_steps=28,
    guidance_scale=4.5,      # CFG 外推强度：越高越贴 prompt 但过饱和
).images[0]

# --- Flux Dev：引导蒸馏（单前向，guidance 已在权重内，仅传标量）---
pipe_flux = FluxPipeline.from_pretrained(
    "black-forest-labs/FLUX.1-dev", torch_dtype=torch.bfloat16
).to("cuda")
img = pipe_flux(

📜 历史注脚：从"咒语工程师"到"消失的岗位"

2022–2023 年，"Stable Diffusion 咒语工程师"一度是真实存在的职业方向：负权重语法、(word:1.3) 强度记号、负面词清单、LoRA 触发词调用……2023 年 10 月 DALL-E 3 发布后，这些技能在半年内贬值殆尽——合成 caption 让自然语言直接可用，社区论坛（如 r/StableDiffusion）的热门帖从"咒语大全"变成了"重标注数据集下载"。教训：当你的工作是在"补偿训练数据的缺陷"时，这个工作注定被数据侧的一次升级清零——识别哪些工程在"补数据的坑"，是 AI 工程师的时间投资课。

7.闭源旗舰与新形态：Imagen 3、GPT-4o 原生生图

Imagen 3（Google，2024）：延续 Imagen 系的 T5-XXL 文本条件 + 级联扩散，公开信息强调数据质量与细节还原；在文字渲染与 photorealism 上是 2024 年闭源第一梯队，配合 Gemini 的对话式生图形成产品闭环。GPT-4o 原生生图（2025 年 3 月）：生成能力内置于多模态 LLM（而非外挂 DALL-E），三个范式级新能力——①对话式多轮编辑（"把背景换成夜晚，人物不动"的迭代精修）；②文图交错输出（在回答中嵌入生成图——第 19 章 Chameleon 愿景的产品化）；③知识增强生成（LLM 的世界知识直接进入生成条件，"画出 XX 论文的示意图"类任务质的飞跃）。其技术路线（自回归+扩散混合或原生 tokenizer）未公开，但市场反馈确认了"理解与生成一体"的产品价值。中文系（可灵、即梦、HunyuanImage、Seedream 等，2024–2026）在中文文字渲染与本土审美上建立了差异化优势，市场格局与 LLM 类似——两条供给线并行。

新形态的共同信号：生成正在从"独立工具"变成"多模态模型的输出模态"。这与第 19 章原生路线的判断一致：当生成内化后，"先理解再画"（按用户草图补全）、"边说边画"、"画完自己改"这些复合能力才成为可能——2025–2026 的竞争焦点已从"单张质量"转向"生成的交互性"。

💡 技巧：面向新一代 T2I 写 prompt 的五条军规

①说人话：完整自然语言句子代替关键词堆砌（训练 caption 就是自然语言）；②先整体后细节：一句话主体+场景，再补风格/构图/光影（模型按 caption 语义顺序解析）；③文字内容加引号原样写：招牌文字、书名直接引用，不要转述；④负面语义改正向：写"空旷的街道"而非"没有人的街道"（无 CFG 蒸馏模型尤其如此）；⑤多轮迭代优于一次长文：对话式编辑模型上，先出底图再逐项修——每轮指令只改一件事。

交互性之外的第二条新战线：多模态上下文生成。2025 年后的旗舰生图（GPT-4o、Gemini 2.5 Flash Image、Qwen-Image-Edit 等）把"参考图"作为一等输入——用户上传 3 张图，要求"把图 1 的人物穿上图 2 的衣服、放进图 3 的场景"。这本质上是IP-Adapter/Reference-only 控制（第 26 章）的产品化内化：不再需要用户拼 ControlNet 工作流，模型在训练中就学会了"条件可以是多张图+指令"。对开源社区的启示：下一代的 ControlNet 类控制正在从"外挂适配器"迁向"训练时多图条件"——控制与生成分离的设计模式（第 26 章的核心）正在被重新融合。

8.评测：从 FID 到 GenEval 的方法论迁移

T2I 评测的三年演进浓缩成一条线：分布指标失灵 → 对齐指标兴起 → 人类偏好定标 → 结构化归因。FID 在开放域 T2I 无意义（无"真分布"）；CLIPScore 免费但被 CLIP 盲点绑架（计数/空间）；HPS v2/ImageReward 用人类标注训练打分器成为定标器；GenEval（arXiv:2310.11513）把 prompt 拆成对象/计数/位置/颜色/文字逐项检查（用检测器+OCR 自动判卷）——从"总分"到"能力归因"的方法论升级，与第 40 章 MLLM 评测的演化同构。生成评测的"反作弊"也已成体系：固定种子/协议公开、防过拟合基准轮换、人工小样本校准（第 24 章三件套的延续）。

人类偏好评测的产品化：Arena 机制。2024 年起，生成模型评测的事实金标准转向匿名对战（Artificial Analysis、LMArena 图像赛道）：用户提交同一 prompt 给两个匿名模型盲选胜者，Elo 分累积。Arena 的优势是"永不固定、无法过拟合"（prompt 来自真实用户分布）；缺陷是偏好偏差（精致但错误 vs 朴素但正确的对决中未必选对）与统计噪声（Elo 需万级对战才收敛）。实践建议：团队选型时"GenEval 定位短板 + Arena 定位口碑 + 自建场景集定位业务"，三角互补；任何单一榜单都不足以签约采购。

📄 论文精读：GenEval（NeurIPS 2023，arXiv:2310.11513）

动机：CLIPScore 一个总分掩盖所有短板——模型可能"整体像"但"计数全错"，用户感知却极差。方法：构造 553 条结构化 prompt（覆盖 6 类能力：单对象/双对象/计数/颜色/位置/属性绑定），用现成感知模型当"阅卷老师"——Grounding DINO 检测对象、count 判数量、坐标判位置、OCR 判文字，逐条自动判卷出分项得分。发现：各代模型的短板高度稳定——计数与位置是最难能力（旗舰模型也只有 0.4–0.6），文字渲染在 2023 年前几乎全军覆没；"总分高"与"分项均衡"不相关。影响：GenEval 确立了生成评测的"结构化归因"范式，DPG-Bench、T2I-CompBench、OneIG-Bench（2025）皆是其后继；第 40 章的 MLLM 评测"分能力矩阵"思想同源。局限：判卷老师自身的错误率（检测器漏检会冤枉模型）、场景窄于开放 prompt。

💻 代码：给 T2I 模型建一个"迷你 GenEval"阅卷器

# 用GroundingDINO+OCR给生成结果按结构化prompt打分（示意核心循环）
CAPS = [
    ("单对象",  "a single wooden chair",       {"obj": ["chair"], "cnt": [1]}),
    ("计数",   "exactly two red apples",      {"obj": ["apple"], "cnt": [2], "color": "red"}),
    ("位置",   "a cat to the left of a dog",  {"obj": ["cat", "dog"], "rel": "left"}),
    ("文字",   'a sign that says "OPEN 24H"', {"text": "OPEN 24H"}),
]
def grade(image, spec, det_model, ocr_model):
    boxes = det_model.detect(image, [o for o in spec.get("obj", [])])
    score = {}
    if "cnt" in spec:
        score["计数"] = any(len(boxes[o]) == c for o, c in zip(spec["obj"], spec["cnt"]))
    if "rel" in spec:  # 位置：比较两类框中心坐标
        score["位置"] = center(boxes[spec["obj"][0]])[0] < center(boxes[spec["obj"][1]])[0]
    if "text" in spec:
        score["文字"] = normalize(ocr_model(image)) == spec["text"]  # 大小写/空格归一
    return score
# 逐能力聚合 → 得到模型的"能力雷达图"而非单一总分

9.本章小结

2023–2026 的 T2I 大跃迁由四条主线合力：DALL-E 3 的重标注确立"caption-图像互信息决定条件生成上限"的第一性原理；rectified flow 用"最直路径"统一了扩散与流、换来少步采样与稳定训练；MMDiT 让文本与图像对等对话、文字渲染破局；Flux 式引导蒸馏把 CFG 内化、部署成本砍半。自回归路线（Parti/LlamaGen/VAR）虽未夺魁，却把多尺度 VQ 与 scaling law 留给了统一模型。闭源侧，GPT-4o 原生生图开启"生成即多模态输出模态"的新形态。至此，第四部分的"理解扩散—解剖 LDM—控制注入—前沿演进"四部曲完成；下一章解决最后一个生成难题：个性化与一致性。

✏️ 自测

1. 用信息论解释"caption-图像互信息决定 prompt 遵循上限"。
答案要点：$p(x|c)$ 的学习受训练对 $(x,c)$ 互信息约束；caption 缺细节则模型学到边缘分布，推理时细节传不进去；咒语学=用户手工调制分布，重标注=从根上修。

2. 写出 rectified flow 的路径与训练目标；"直路径"为什么带来少步采样？
答案要点：$x_t=(1-t)x_0+t x_1$，回归 $v=x_1-x_0$；直路径下速度场接近常数，ODE 数值积分容错大——20 步可达 250 步扩散质量。

3. MMDiT 与 SD1.5 交叉注意力的本质区别？"对称性"带来什么？
答案要点：MMDiT 文本/图像双套投影、同一注意力互为 K/V（对等对话 vs 单向查询）；收益是属性绑定与文字渲染，代价是长 prompt 成本耦合。

4. VAR 对 AR-T2I 的两个关键改进？
答案要点：多尺度 VQ 由粗到细（复杂度降、粒度分离）+ 首次复现 AR 路线 scaling law。

5. 引导蒸馏蒸馏掉了什么？省了多少？
答案要点：把 CFG 的"条件-无条件双前向外推"蒸进权重（引导标量输入）；省一半推理算力，Flux 免 CFG。

榜单的暗面：生成评测同样面临 Goodhart 定律——HPS v2 被 RLHF 目标采用后，"讨好评分器"的风格漂移已在部分开源模型上出现（过饱和、过细节的"AI 味"）；GenEval 检测器（Grounding DINO）的漏检会系统性冤枉特定风格模型。防御三件套与第 40 章一致：私有测试集 + 判卷器轮换 + 人工抽检定标。健康的评测观：榜单是体检报告，不是奖杯——它告诉你哪里异常，不能替代你对自己业务分布的观察。

7. 为什么蒸馏后的模型（Flux Schnell/Turbo）不能用 negative prompt？
答案要点：步数蒸馏训练时无 CFG 双分支（单前向），推理时也无条件分支可外推；负面语义需改写进正向 prompt 或用 LoRA 微调实现。

8. 重标注数据的"固有税"是什么？
答案要点：captioner 幻觉会把不存在的内容写进 caption，模型学到"凭空添加"先验；缓解：caption 置信度过滤、多 captioner 投票、混合原始 alt-text。

6. GPT-4o 原生生图的三个范式级新能力？其战略意义？
答案要点：对话式多轮编辑、文图交错输出、知识增强生成；生成内化为多模态 LLM 的输出模态，竞争焦点转向交互性。
