第 52 章 术语表

附录 · 全书核心专业术语全景释义 · 涵盖多模态表示、扩散流匹配、视觉定位、具身智能与系统架构中英文权威对照

多模态大模型是一个交叉融合了计算机视觉（CV）、自然语言处理（NLP）、统计物理学（非平衡态扩散热力学）、机器人运动学以及高性能异构计算系统的庞大前沿学科。在过去数年的狂飙突进中，来自不同学术流派的文献创造了大量崭新且易混淆的专业名词——例如：很多初学者容易将“动态切片（AnyRes）”与“分块解码（Tiled VAE）”混为一谈；将“隐空间文本反演（Textual Inversion）”与“解耦交叉注意力（IP-Adapter）”视作同一机制；或者在面对“流匹配（Flow Matching）”、“自回归统一”与“具身动作块（Action Chunks）”时难以厘清其底层数学本质。

为了消除跨学科交流中的术语歧义，建立严谨统一的技术语言基线，本附录精选了全书 55 个章节中最核心、最高频出现的 30 余个核心专业概念，严格按照“标准英文原名 · 权威中文译名 · 核心数学与系统机理阐释 · 关联前沿章节指引”的标准词条结构进行了深度规范化定义，旨在为读者提供一本权威、可随时案头查阅的多模态大模型学术与工程词典。

历史演进：多模态技术词汇的代际更迭

技术术语的诞生与消亡折射出技术范式的深刻演进：

  • 感知对齐时代（2020–2022）：这一时期的核心词汇聚焦在“双塔（Dual-Tower）”、“跨模态对比损失（InfoNCE）”、“掩码语言图像建模（MIM/MLM）”与“区域建议网络（RPN）”，模型的核心任务是在向量空间中完成图文匹配与分类检索。
  • 大模型与潜变量扩散时代（2023–2024）：词汇重心迅速向“自回归指令微调（Visual Instruction Tuning）”、“潜在扩散模型（Latent Diffusion）”、“无分类器引导（CFG）”、“零卷积（Zero Convolutions）”与“动态分辨率网格（Dynamic Tiling）”转移。
  • 通用世界模型与具身推理时代（2025–2026）：当前最硬核的技术词汇全面聚焦于“整流流匹配（Rectified Flow）”、“测试时计算扩展（Test-Time Compute Scaling）”、“多模态旋转位置编码（M-RoPE）”、“因果动作流（Flow Matching VLA）”与“解耦表征统一（Decoupled Multimodal Foundation）”。
理论框架：多模态大模型五大核心技术支柱词谱分类法

为了帮助读者建立结构化的技术认知图谱，全书的术语体系可以解构为五大相互咬合的技术支柱：

  1. 表示与编码支柱（Representation & Encoding）：研究高维连续信号（像素、声音）如何有损或无损地压缩投影为低维特征空间。核心概念涵盖：CLIP、SigLIP、NaViT、AnyRes、M-RoPE 与 VQ-VAE；
  2. 融合与主干支柱（Fusion & Backbone Architectures）：研究视觉特征与文本序列在 Transformer 内部如何进行注意力拓扑交互。核心概念涵盖：Cross-Attention、Early-Fusion、Decoupled Representations 与 FlashAttention；
  3. 生成与物理动力学支柱（Generative Modeling & Physics）：研究如何从纯随机高斯白噪声出发，依据文本引导逐步采样出高维连续数据。核心概念涵盖：Score SDE、Flow Matching、MMDiT、ControlNet 与 IP-Adapter；
  4. 细粒度空间感知与具身控制支柱（Spatial Grounding & Embodied VLA）：研究模型如何跳出抽象宏观语义，精准理解现实世界的二维与三维几何坐标。核心概念涵盖：REC、REG、SoM、6-DoF Grasping 与 Action Chunks；
  5. 系统工程与安全对齐支柱（Systems & Alignment Governance）：研究模型如何高吞吐、低显存部署，并抵御对抗攻击。核心概念涵盖：PagedAttention、RadixAttention、Tree-Ring Watermark、C2PA 与 Multimodal DPO。
论文精读：Chinchilla、Llama 与现代多模态扩展定律的术语界定

在 DeepMind 经典的 Training Compute-Optimal Large Language Models（NeurIPS 2022）与后续系列多模态扩展定律研究中，学术界确立了一批关于模型计算与数据规模的严格度量术语：

  • 浮点运算总次数（FLOPs: Floating Point Operations）：衡量模型训练与推理消耗的纯粹数学计算量。对于标准 Transformer，单步前向传播每个 Token 大约消耗 $2N$ FLOPs（$N$ 为非 Embedding 参数量），反向传播消耗 $4N$ FLOPs，训练一个 Token 共需 $6N$ FLOPs；
  • 模型浮点利用率（MFU: Model FLOPs Utilization）：评估真实 GPU 集群硬件效率的核心黄金指标。计算公式为 $ ext{MFU} = rac{ ext{实际吞吐计算量}}{ ext{硬件理论标称峰值算力}}$。优秀的高性能多模态训练框架通常能够达到 45%~58% 的 MFU；
  • 无分类器引导外推度量（CFG Scale / Extrapolation）：在条件扩散采样中，通过外推因子 $s \ge 1.0$ 放大条件去噪向量与无条件去噪向量的差值向量，用生成样本多样性的适度收缩，换取极高文本遵循度与细节锐利度的核心调控旋钮。

52.1 核心术语深度释义条目（Alphabetical Reference）

Vision-Language Model (VLM) · 视觉语言模型

将高维视觉输入（图像、视频）与自然语言处理（LLM）有机结合的大型多模态神经网络基座。通常由视觉编码器、跨模态投影层与因果语言解码器三部分构成。在训练中，通过大量图文对与交织图文序列，使模型不仅能看懂画面微观与宏观实体，更能依据指令进行逻辑推理与结构化输出。

CLIP (Contrastive Language-Image Pre-training) · 对比语言-图像预训练

OpenAI 于 2021 年提出的双塔自监督预训练范式。通过在数亿图文对上最大化正样本对的余弦相似度、最小化负样本对相似度（InfoNCE 损失），将图像与文本映射至同一统一高维度量空间，开启了多模态表征学习的现代纪元。

SigLIP (Sigmoid Loss for Language-Image Pre-training) · Sigmoid 损失图文预训练

Google 提出的替代经典 Softmax 对比学习损失的方案。将成对匹配转化为二分类交叉熵，彻底消除全局 Softmax 的归一化常数，从而支持极大的 Batch Size 且显著提升训练稳定性与微观表征质量，成为现代前沿 VLM（如 Janus、PaliGemma）首选的视觉基座。

Patch Tiling / AnyRes · 动态图像切片 / 任意分辨率适配

为应对高分辨率图像超出 ViT 最大输入限制的技术。将高分辨率大图按照最匹配的宽高比网格切分为多个局部图块（Patches），分别送入标准视觉编码器提取局部细节，最后拼接全局缩略图注入大语言模型，完美解决细小文字与密集表格模糊失真的问题。

M-RoPE (Multimodal Rotary Position Embedding) · 多模态旋转位置编码

Qwen2-VL 提出的多维时空位置编码技术。将传统的一维 RoPE 向量通道解耦为时间（Temporal）、高度（Height）、宽度（Width）三个独立子空间，赋予每个视觉 Token 原生物理二维空间欧氏距离与时间动态感知，彻底消除切片边缘的几何撕裂。

Rectified Flow / Flow Matching · 整流流匹配

现代生成模型前沿架构（如 SD3、Flux.1）。将从高斯先验噪声到真实图像分布的扩散轨迹建模为一条常微分方程（ODE）的最短直线速度场，大幅降低采样曲率，在 15~20 步内即可达到高质量收敛，训练稳定度远超传统 DDPM。

MMDiT (Multimodal Diffusion Transformer) · 多模态扩散 Transformer

Stable Diffusion 3 提出的双流生成主干网络。文本与图像模态拥有完全独立的线性变换与归一化参数，但在多头注意力计算时共享同一全局注意力场，实现文本语义与画面特征的深度双向交叉渗透。

Guidance Distillation · 无分类器引导蒸馏

将传统扩散模型在推理时需要进行的两次前向传播（一次有条件、一次无条件计算 CFG 外推）通过知识蒸馏合并为一个单次前向网络，使生图推理延迟直接减少 50%，代表模型如 Flux.1-schnell，极大加速了商业实时出图应用。

Decoupled Visual Representation · 解耦视觉表征

DeepSeek Janus 提出的突破性架构范式。将多模态理解所需的高层语义抽象特征（SigLIP）与图像生成所需的低层离散高频量化特征（VQ 代码本）在输入与输出端彻底分离，单一 LLM 主干仅作为两者的通用调度大脑，从根源上化解了表征冲突。

REC (Referring Expression Comprehension) · 指代表达理解

细粒度视觉定位核心任务：给定图像与自然语言短语（例如'穿条纹衬衫正在喝咖啡的男孩'），模型在图像中预测出该目标物体的精确 2D 归一化空间包围框坐标 [xmin, ymin, xmax, ymax]，取值通常为 0~1000 整数。

REG (Referring Expression Generation) · 指代表达生成

REC 的逆任务：给定图像中的指定空间区域框，模型自动生成一段独具辨识度的自然语言文本，使其能够精确区别于场景中的同类干扰物体，实现精准的视觉语义反演。

Dense Visual Grounding · 密集图文接地

在模型进行整图多轮对话或长篇解说时，自动在生成的每一个名词短语后插入对应的实体空间边界框坐标，实现'言出有据、指代分明'的像素级图文深度绑定。

Set-of-Mark (SoM) · 标记集合标注法

微软与 AppAgent 倡导的视觉感知预处理范式：通过前置检测器在截屏的各个可交互控件上叠加半透明彩色数字编号角标，模型只需输出角标编号即可完成精准点击，避免坐标浮点微小漂移。

POMDP (Partially Observable Markov Decision Process) · 部分可观测马尔可夫决策过程

GUI Agent 与具身机器人的数学理论基石：环境真实状态包含操作系统内核内存等不可见信息，智能体只能依靠历史截屏观测、动作历史与反思状态机来求解下一步最优鼠标与键盘策略。

OSWorld · 操作系统真实执行基准

加州大学伯克利分校等构建的端到端真实桌面操作系统评测环境。内置 LibreOffice、Chrome、VS Code、GIMP 等完整应用，通过底层文件内容与系统运行断言进行绝对客观的自动化能力评定。

IP-Adapter (Image Prompt Adapter) · 图像提示词适配器

腾讯开源的免微调条件注入框架。通过解耦交叉注意力（Decoupled Cross-Attention）将参考图像的特征独立注入扩散模型，实现特定人脸、风格或商品的高一致性即插即用迁移。

DreamBooth · 主题驱动个性化微调

Google 提出的个性化生成算法。仅需特定主体的 3~5 张照片，通过引入类先验保留损失（Prior Preservation Loss），在保留基座模型通用泛化能力的同时，将特定主体绑定至罕见标识符。

C2PA (Coalition for Content Provenance and Authenticity) · 内容来源与真实性联盟标准

由全球科技巨头联合推进的数字内容认证协议。通过在图片与视频元数据中写入包含数字证书、模型版本与提示词哈希的密码学签名，实现 AIGC 全链路合规可追溯。

Tree-Ring Watermarks · 年轮隐形水印

马里兰大学提出的扩散模型频域盲水印技术。在扩散去噪初始高斯随机噪声的低频傅里叶变换相位中嵌入特定同心圆图案，其频域特征在去噪动力学中严格守恒，耐受剧烈有损压缩与二次裁剪。

Visual CoT (Visual Chain-of-Thought) · 视觉思维链

在复杂视觉推理难题中，模型通过生成多步反思文字，主动自发向环境派发'局部高清放大、调用外部工具、自我推翻猜想'的动态探索闭环过程，显著突破单次前向的智力瓶颈。

Test-Time Compute Scaling · 测试时计算扩展法则

大模型第二定律：在推理阶段通过增加思考 Token 长度、开展蒙特卡洛树搜索（MCTS）与验证自纠错，使模型在无需扩充参数的前提下实现推理智力的大幅跃迁。

VLA (Vision-Language-Action) · 视觉-语言-动作具身模型

将机器人机械臂末端 6 自由度位移、旋转欧拉角与夹爪动作直接 Token 化或连续流匹配化，与预训练多模态大模型统合的通用物理具身控制架构，赋能通用家庭与工厂自动化。

ColPali · 基于后交互的多模态检索模型

基于多模态大模型（PaliGemma）的端到端文档检索架构。将页面切片直接映射为高维多向量，通过 MaxSim 晚期交互对齐用户查询词，彻底颠覆传统基于纯文本切片与 OCR 的知识库方案。

Late Interaction / MaxSim · 晚期交互 / 最大相似度算子

ColBERT 与 ColPali 的核心计算算子：查询句中的每个 Token 向量与文档中的全部视觉 Patch 向量计算内积并取最大值，最后累加求和，完美保留微观细粒度视觉实体匹配。

M-DPO (Multimodal Direct Preference Optimization) · 多模态直接偏好优化

无需训练复杂强化学习价值网络（Reward Model），直接基于由同一图像引导出的正反候选回复对（Winning vs. Losing Response）进行闭式损失反向传播的偏好对齐算法。

FastV · 视觉注意力衰减剪枝

针对 VLM 推理预填充阶段视觉 Token 过多导致的延迟问题。发现 Transformer 浅层（前两层）之后注意力极度向文本聚集，在中间层直接暴力剪枝 45% 以上非核心视觉 Token 的加速技术。

RadixAttention · 基数树前缀注意力缓存

SGLang 提出的树状结构 KV Cache 自动管理机制。允许多个并发请求无缝复用前序共享的系统 Prompt、长篇历史与高分辨率大图嵌入，将首字生成延迟降低数倍。

PagedAttention · 分页注意力内存管理

vLLM 借鉴操作系统虚拟内存分页设计的非连续物理显存管理技术。彻底消除了传统连续分配带来的显存碎片化浪费，大幅提升多模态推理的并发吞吐能力。

AWQ (Activation-aware Weight Quantization) · 激活感知权重仅量化

发现网络中仅有 1% 的显著激活通道决定了模型的核心精度。通过保护这 1% 的关键通道并缩放权重，使 4-bit 权重仅量化在多模态基准上保持 99% 以上原有精度。

Typographic Attack · 印刷字体排版攻击

多模态越狱经典攻击：将恶意文本指令直接渲染为带有手写体、倾斜透视或艺术噪点的图像，利用视觉编码器绕过文本分词器的过滤网关，诱导大模型输出违禁内容。

52.2 易混淆多模态概念深度辨析专题（Conceptual Disambiguation）

在多模态工程实践与学术面试中，很多概念表面相似，底层机制却截然不同：

vs.

工程实战检查表：多模态技术方案设计中的术语精确性把控

在撰写工程技术方案书或多模态算法立项报告时，请遵循以下行业规范用语：

  • 当描述将图片输入大语言模型时，应称之为“视觉特征投影映射（Visual Projection / Feature Alignment）”，严禁使用“把图片转成字符串”等不规范口语；
  • 当描述在扩散模型中保持人物脸型时，应严格区分“几何关键点约束（Spatial Control / OpenPose / Landmarks）”与“身份特征向量注入（Identity Embedding / InsightFace / FaceID）”；
  • 当描述大模型在屏幕上点击按钮时，应使用标准学术名词“细粒度视觉接地（Fine-Grained Grounding）”或“GUI 动作策略推断（GUI Policy Inference）”。

52.3 常用核心前沿术语补充详解（Extended Lexicon）

为了进一步满足科研阅读与工程进阶需求，本节对前沿论文中出现的更多关键机制术语进行系统补充：

Diffusion Transformer (DiT) · 扩散 Transformer

将传统基于 U-Net 的卷积去噪骨干网络全面替换为基于标准各向同性 Transformer 的生成架构（Peebles & Xie, 2023）。通过将潜在空间特征切片为 Token 序列，直接继承了 Transformer 极佳的参数与计算缩放法则（Scaling Law），成为 Sora、SD3、Flux 等现代生成模型的标配架构。

Classifier-Free Guidance (CFG) · 无分类器引导

Ho & Salimans 于 2021 年提出的条件扩散采样增强技术。在训练时以一定概率随机丢弃条件提示词，在推理时计算有条件得分与无条件得分的外推差值向量：$\epsilon^* = \epsilon_{\text{uncond}} + s \cdot (\epsilon_{\text{cond}} - \epsilon_{\text{uncond}})$，显著增强图像细节锐利度与文本依从性。

Score-based Generative Models (SGM) · 基于分数的生成模型

由宋飏等提出的生成模型理论体系。将扩散去噪过程统一表述为随机微分方程（Score SDE），通过神经网络拟合数据分布对数梯度的分数函数（Score Function $\nabla_x \log p(x)$），完美统一了朗之万动力学与反向去噪扩散模型。

FlashAttention / FlashAttention-2 · 快速显存感知注意力

由斯坦福大学 Tri Dao 提出的 GPU 显存 IO 感知精确注意力算子。利用片上高带宽 SRAM 进行分块计算与在线 Softmax 统计量重缩放，彻底消除了显存中间大矩阵写出开销，带来数倍训练加速与显存节省，是当代大模型长上下文的基石。

Group Relative Policy Optimization (GRPO) · 群相对策略优化

DeepSeek-Math 与 DeepSeek-R1 提出的强化学习对齐算子。无需训练独立的评判家网络（Critic Model），通过对同一 Prompt 采样出的若干个候选轨迹在组内计算相对归一化奖励，将多模态强化学习显存开销降低近半，强力驱动了视觉推理长思维链（Visual RLVR）。

Cross-Attention Map Masking · 交叉注意力图掩码隔离

多主体个性化生成中的防串色防换脸技术。通过在去噪过程中将特定人物或物体的图像提示词嵌入限制在局部空间掩码内，从注意力底层切断多角色之间的属性混淆，实现多主体复杂互动的精准渲染。

Action Chunks (连续动作块) · 动作块时序预测

具身智能机器人控制中的高频时序优化机制：模型单次前向不预测孤立的下一毫秒动作，而是连续输出未来 0.5~1.0 秒内的平滑轨迹点序列（如 π0），大幅增强机械臂运动的动力学顺滑性并降低控制延迟。

Model FLOPs Utilization (MFU) · 模型算力利用率

衡量分布式大模型训练与推理系统吞吐效率的核心物理指标，即硬件执行实际有用矩阵乘法的吞吐量占 GPU 芯片标称理论峰值算力的真实百分比。优秀的高性能多模态训练框架通常能够达到 45%~58% 的 MFU。

Latent Consistency Model (LCM) · 潜在一致性模型

由清华大学团队提出的扩散模型快速蒸馏技术。通过直接预测 ODE 积分轨迹上的自洽初值映射，使原本需要数十步迭代的扩散过程在 2~4 步内极速完成，奠定了实时 AIGC 生成工作流的基石。

Zero-Shot Referential Grounding · 零样本指代接地

模型在面对预训练中从未见过的生僻概念、长尾工业零件或抽象修饰语时，仅凭常识泛化与多模态空间对齐，直接定位出该未知目标真实空间几何坐标的能力，是衡量视觉定位模型通用泛化性的核心标准。

Poisson Blending Latent Inpainting · 泊松融合隐空间局部重绘

将经典图像处理中的泊松微分方程延伸至扩散模型的隐空间中。在执行商品试穿或消除路人时，确保重绘区域边缘与保留区域的梯度场完美光滑衔接，彻底消除生硬拼贴接缝与色彩突变。

Hierarchical Task Network (HTN) · 分层任务网络规划

多模态 Agent 处理长程多步骤复杂任务时的高级架构。将用户自然语言长目标逐级解构为带可验证状态断言的子目标 DAG 依赖图，并由底层微观执行器逐项打卡执行，避免单步复合误差雪崩。

Visual Prompt Injection · 视觉提示注入攻击

针对多模态大模型的安全对抗手段：在输入图像的背景或微观像素中隐蔽嵌入恶意指令文字，诱导具有 OCR 能力的多模态模型将图片文字误当作系统元指令执行，撕开语言安全护栏。

Thin-Plate Spline (TPS) Rectification · 薄板样条几何去畸变

用于高分辨率弯曲文档、折叠发票的非刚性曲面展开算法。通过在文本行周边拟合弹性薄板能量最小化样条网格，将非线性扭曲的票据字符重新映射为平直水平光栅，提升 OCR 准确率。

Reading Order Disambiguation · 阅读顺序几何语义消歧

文档理解大模型对多栏学术论文、报纸复杂穿插排版进行解析的核心能力：结合视觉分割边界与文本语法连贯性，智能判定从左栏、跨栏图表到右栏的真实逻辑阅读流，避免腰斩式误读。

Hand-Eye Calibration · 手眼系统空间几何标定

具身控制中解算相机三维光学坐标系与机器人机械臂基座世界坐标系之间刚体变换矩阵 $[R \mid t]$ 的数学工序，直接决定了视觉抓取能否精准命中目标而不发生碰撞与偏移。

52.4 多模态模型系统工程与推理加速词汇全景

随着多模态大模型进入万亿级请求的工业生产线，模型推理优化不再是单纯的数值计算，而是与异构显存架构、网络拓扑与编译流水线深度绑定的跨学科工程。本节系统收录支撑高性能服务化的核心底层术语：

系统术语 英文全称 所属层级 核心机制与工程价值
TTFT Time to First Token 在线服务性能 大模型从接收到多模态 Prompt（含大图处理）到吐出第一个文字的端到端时延，主要由高分辨率图像特征提取与预填充（Prefill）阶段的计算开销决定。
TPOT Time Per Output Token 在线服务性能 在生成阶段，自回归输出每个后续 Token 的平均耗时，受限于 GPU 高带宽显存（HBM）的访存带宽瓶颈。
KV Cache Key-Value Cache 显存优化 自注意力机制中将前序所有 Token 计算得到的 Key 和 Value 矩阵保存在显存中，避免自回归生成时的二次方重复前向计算。
Kernel Fusion 算子融合 编译器编译 将连续调用的多个小 CUDA 核心（如 LayerNorm + GELU + Linear）融合成单个复合 GPU Kernel，消减中间张量在显存与片上缓存间的往返搬运。
Chunked Prefill 分块预填充 推理调度 将超长多模态大图带来的巨量视觉 Token 切分为固定大小的计算块，与解码（Decode）请求交错混合调度，平抑首字延迟突刺并防止长尾阻塞。
Speculative Decoding 投机推测解码 推理加速 使用微缩草稿小模型（Draft Model）快速连续预测多个候选 Token，再由大模型单次前向并行验证，在完全保证数学精度无损的前提下实现 2~3 倍生成加速。
Continuous Batching 连续动态批处理 调度优化 在生成阶段以 Token 为粒度动态管理批次，一个序列完成生成后立即退出发射新请求，彻底消除短句子等待长句子的显存空转气泡（Bubble）。
Activation Outliers 激活值离群异常通道 模型量化 Transformer 隐层特征中特定几个维度数值异常巨大（超过均值百倍）的物理现象。量化算法必须保护这些异常通道不发生截断以维持模型逻辑推理能力。
FlashDecoding 快速解码注意力 算子优化 针对长上下文解码阶段将注意力计算沿 Key-Value 序列维度进行分块多线程并行归约，使超长文档下的单个 Token 解码吞吐提升数倍。

自测题与术语思辨
  1. 术语深度思辨：为什么在现代前沿多模态大模型论文中，“跨模态对齐（Cross-Modal Alignment）”的内涵已经从早期的“粗粒度整图图文余弦相似度匹配”，演变为了“空间几何、因果逻辑与人类意图的三重对齐”？
    查看解析

    在以 CLIP 为代表的早期时代，“对齐”仅仅指统计层面的表征对齐（Statistical Representation Alignment），即把整张图的高层概念向量与描述句子的向量拉近，忽略了微观空间位置、从属关系与因果逻辑。而在现代通用多模态基础模型（MLLM/VLM）语境下，“对齐”已经升华为了三个严密层级：（1）物理空间对齐（Spatial Grounding Alignment）：文本中的每个实体必须精准绑定到像素坐标或三维刚体位姿；（2）因果时空对齐（Spatiotemporal Causal Alignment）：视频与连续动作流中前因后果的演变必须符合真实物理世界的守恒规律；（3）人类偏好与安全对齐（Human Value & Safety Alignment）：模型必须在遵循复杂人类长文本指令的同时，具备主动拒绝有害越狱与偏见消除的安全自律能力。
